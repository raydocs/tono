TUN routes v4/v6 (LAN/CGNAT/link-local/multicast excluded), DNS hijack with fake IP, IPv6-change reload, sleep/wake, screen state. The extension holds **no tokens** and re-admits the catalog itself.

## Round 4: widgets, Live Activity, Control Center switch, onboarding

- **`TonoWidgets` extension** (iOS 17+): status widget (Home Screen small/medium, Lock Screen circular/rectangular/inline), Live Activity (Lock Screen + Dynamic Island, 15-min stale date), iOS 18 Control Center switch. All read one `StatusSnapshot` in the App Group, written by the app and by the tunnel (5-min heartbeat): ≤15 min = current state, older = "Last known · time", none = "Status unavailable". Never a guessed "off".
- The only outside command is `SetTunnelIntent` (runs in the app process via `LiveActivityIntent`), gated by `TunnelCommandGate` (account, enabled VPN configuration, admitted inputs). Stopping is always allowed. Live Activity defaults off (decision 130, provisional). DEBUG previews never write the shared state; every fixture rendering carries a "Preview" tag.
- Onboarding, an explanation before the iOS VPN prompt, network-changed "reconnecting", dropped + Retry, offline, lines loading/empty. Haptics (`HapticCue`) and title/failure motion follow Android. 120 Hz opt-in (`CADisableMinimumFrameDurationOnPhone`).

## Round 6: independent reviews and rework

Two independent blind reviews, committed verbatim in `docs/agent-reports/2026-10-18-mobile-*` (`aa4a751`): Opus 5.5 iOS 83, GPT-6.1 Sol iOS 83 (different cutoffs and heads; not a strict A/B). Worked from the union, shared items first:
- Settings entry in the bottom row (glass circle, scaled glyph; UI test asserts the bottom third); one line per mode in Settings and Details.
- Stale widgets / Lock Screen / Live Activity are titled "Status unknown" with "Last known: Connected at …" in the small print, never "Connected".
- A dropped session is titled "Connection dropped" ("iOS will try to reconnect"); a network change "Reconnecting".
- Cloud exit not answering: Details' "Other line" opens the line picker (was dismiss only).
- Settings route-check field wraps (the audit red at `159ebad`); primary capsule at AX sizes puts the timer under the label; status dots scale.
- One naming system: lines by city (label only when two share a city), status line names only Home's country; zh copy without "Home" / "Dawn".
- Live Activity preview no longer breaks "Connect-ed"; gallery content no longer under the clock.
- The real widget in SpringBoard's own gallery and placed on the simulator Home Screen, reading the real shared status ("Status unavailable": the preview never writes it).
- Not adopted: disabling Connect while offline (Android does not; connecting also arms On Demand).

## Round 7: glass, motion, fewer words, back paths

- Glass takes the sky's colour (indigo at night, rose with the sun up, ember on trouble) with a rim lit from above and a light upper sheen, instead of a night tint that read as dark pills.
- A network change is its own state. The sun holds near day height and a light runs down the reflection. The capsule keeps its warm edge and the session clock (iOS keeps the connected date while reasserting) and never replays the first-start sunrise. The connected → reconnecting replay seen in `state-cycle-en.mp4` at `fc9c812` came from `onChange` reading the previous `reason`; it is now keyed on phase and reconnecting together.
- Titles, status lines and the capsule label swap in sequence: the old text leaves in 100 ms, then the new one arrives. Checked frame by frame in `state-cycle-en.mp4`: no frame shows two titles.
- Fewer words:
  - Settings: the "applies immediately" line and the widgets paragraph are gone, and the Include-all and Live Activity lines are shorter (34 fewer visible words).
  - Details: mode rows are titles only, because the routes directly above already show what the mode does.
- New UI tests:
  - Every Home entry sits in the lower half and every sheet (Lines, Details, Settings, Details → Settings) closes with a swipe straight back to Home.
  - A start interrupted by the line picker plus an app switch arrives at Connected.
- Preview tags sit in one corner on Home Screen widgets and under Lock Screen widgets, with a yellow outline instead of a solid block. The fixtures badge lives in the gallery's top strip.
