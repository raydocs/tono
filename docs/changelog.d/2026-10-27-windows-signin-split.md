## 2026-10-27 · Windows 海面登录页改为左右分屏（B 方案）
- 归属：G1（客户路径 UI）；Windows 海面外观登录页。
- 来源：基线 main 498765edb；分支 `amp/windows-signin-split`；未合 main。依据用户选定的 B 分屏概念图，以现有产品风格和真实功能为准（概念图里的「收不到验证码？」链接、单独的「验证」按钮文案等没有照搬）。
- 新增/优化：窗口宽度 ≥760px（应用最小窗口 860×540 始终满足）时，左侧是海面场景和品牌文案（`tono.login.brandLabel/Title/Description`，只有文字，不新增标题或控件），右侧是不透明表单面板，顶到透明标题栏下，窗口按钮落在面板上；表单比窗口高时在面板内滚动（`justify-content: safe center`），场景不动。窄于 760px（浏览器缩放、大字号）退回原来的玻璃卡片。账号暂停/套餐到期页不分屏。品牌文案入场动画遵守减少动态效果。
- 缺陷修复：无。
- 工程与测试：`login.test.tsx` 新增 1 个 `it`（分屏文案只含文字、暂停页不渲染；在旧 login.tsx 上为红）。
