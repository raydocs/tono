## 2026-11-27 · 按节点目录可选下发 Hysteria 2 下行 `down-mbps` 与服务端即时开关

- 归属：G1/G2 桌面端 + 控制面 + 节点运维（Option C 第 2 步）；分支 `feat/hy2-per-node-down-mbps`。
- 来源：`origin/main` → 本分支（按所有者在 2026-11-27 拍板的方案 C 实现，参见 [决策 141](../decisions/141-2026-11-27-hy2-per-node-down-mbps-opt-in.md)）。
- 缺陷修复：无（不带硬编码全局 `50/200` Brutal）。
- 新增/优化：
  1. **控制面与发布端目录校验**：[catalog-yaml.ts](../../services/control-plane/src/catalog-yaml.ts) 与 [publish-managed-catalog.rb](../../tooling/scripts/publish-managed-catalog.rb) 对 ` · hy2` 条目放行可选 unquoted 块级整数字段 `down-mbps`（范围 `10..500`，禁止引号键/引号值/尾注释/嵌套/flow-mapping/重复键，VLESS 禁止携带且全局禁用 `up-mbps`），默认未填写时行为零变化。
  2. **Windows 核心**：[node.rs](../../apps/windows/crates/tono-core/src/node.rs)、[config.rs](../../apps/windows/crates/tono-core/src/config.rs) 与 [sing_box/runtime.rs](../../apps/windows/crates/tono-core/src/sing_box/runtime.rs) 读取可选 `down-mbps`（`10..=500`）并仅在存在时写入 `sing-box` `hysteria2` outbound 的 `down_mbps`；永不发射 `up_mbps`（上行保持自适应 QUIC+BBR），Mihomo 回退路径剔除该字段；未配置节点行为与之前逐字节一致。
  3. **macOS 客户端**：[ProxyNode.swift](../../apps/macos/Tono/Models/ProxyNode.swift)、[ConfigParser.swift](../../apps/macos/Tono/Services/ConfigParser.swift)、[ConfigPipeline+Nodes.swift](../../apps/macos/Tono/Core/Configuration/ConfigPipeline+Nodes.swift)、[ConfigPipeline+SingBoxProduct.swift](../../apps/macos/Tono/Core/Configuration/ConfigPipeline+SingBoxProduct.swift) 解析并校验 `down-mbps`（拒绝前导零，越界安全降级为 nil 回落 BBR），仅输出可选 `down_mbps`、`up_mbps` 永不输出；不触发 `HelperProtocolVersion` 升级或 helper 重编。
  4. **服务端即时开关**：[manage-tono-hy2-node.sh](../../tooling/scripts/remote/manage-tono-hy2-node.sh) 新增 `set-bandwidth`（支持 `--ignore-client-bandwidth true|false`、`--up-mbps`、`--down-mbps` `[10..1000]` 及 `--dry-run`；注意 `>500` 仅限服务端上限不透传客户端目录），配置变更后重启 `tono-hy2`（会断开存量 hy2 会话但保留 `tono-xray` PID 不变）并执行 UDP 端口绑定与 `MainPID`/`NRestarts` 稳定性校验，任何失败（含权限/重启失败）自动恢复备份并二次验活；使用 `--ignore-client-bandwidth true` 作为跨平台应急关闭总闸。
- 工程与测试：补充控制面 [catalog-yaml.test.ts](../../services/control-plane/test/catalog-yaml.test.ts)、目录发布 [publish-managed-catalog.test.rb](../../tooling/scripts/tests/publish-managed-catalog.test.rb)、Rust [node.rs](../../apps/windows/crates/tono-core/src/node.rs) / [config.rs](../../apps/windows/crates/tono-core/src/config.rs) / [runtime.rs](../../apps/windows/crates/tono-core/src/sing_box/runtime.rs)、Swift [SingBoxConfigTests.swift](../../apps/macos/TonoTests/SingBoxConfigTests.swift) 与 [test_manage_tono_hy2_node.py](../../tooling/scripts/tests/test_manage_tono_hy2_node.py) 单元测试，并在 [services-ci.yml](../../.github/workflows/services-ci.yml) 接入执行。
- 验证：本地运行控制面 `typecheck` + 单测、`tono-core` 单测、`tono-windows` 编译检查、`swiftc -parse`、脚本/Ruby 单测、`test-suite-reachability.sh`、`records.mjs` 与 `git diff --check`；原生 macOS `xcodebuild test`、`connect-bench`、`ops-console-e2e` 与 Windows `service` 套件由托管 `ci-gate` 执行。
- 候选/发布：仅源码 Draft PR，不发布或部署生产。
