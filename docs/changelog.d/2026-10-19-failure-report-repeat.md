## 2026-10-19 · macOS 同一失败十分钟内只单独上报一次

- 归属：客户 0.0.77 测试反馈「错误信息与重试机制不足」（失败上报出现 HTTP 429）；macOS 账户遥测。
- 来源：`origin/main` `2e602f2ab` →（修复提交见 PR）；分支 `fix/failure-report-dedupe`；未合 main。
- 缺陷修复：每次连接失败都会立即单独上报到 `telemetry/failures`，服务端给每个账户每小时 12 次。重试循环反复撞同一个失败时几分钟就用完额度，之后的上报全部 429，而 429 不会进离线队列，等于丢失。现在同一失败（阶段、代码、错误文本、节点都相同）十分钟内只单独上报一次；换了失败，或过了十分钟，照常立即上报。周期窗口和五分钟后的跟进窗口不受影响。
- 新增/优化：无。
- 工程与测试：`AccountSession.admitConnectFailureReport`；新增 `ConnectFailureReportRepeatTests`。
- 验证：由托管 CI 跑，结果见 PR 验证评论。
- 候选/发布：仅源码，无新候选。
- 剩余限制：服务端额度没变；快照开关关闭时，周期窗口不带失败事件，被压掉的重复失败不再计数。
