## 2026-10-12 · 运维台：键盘与读屏可用
- 归属：ops 计划（[plan-2026-09-11](../ops/plan-2026-09-11.md)）；`services/ops-console`，仅前端，无服务端改动。
- 来源：基线 `feat/ops-maturity-r1`（c12b474d0，叠在其上，合入顺序：先 r1）→ 分支 `feat/ops-a11y`；未合 main。
- 缺陷修复：
  - 焦点环：全局一条 `:focus-visible` 规则（颜色取新定义在 `tokens.css` 的 `--focus-ring`，深色用 #8f84ff）；去掉十处没有替代的 `outline-none`（偏好菜单、搜索框、跟进备注、关闭弹窗、发布表、回复草稿、编辑器、设置表单、导入弹窗、登记发布抽屉、节点确认框）。
  - 不可点的动作（`Action`）：由 `disabled` 改 `aria-disabled`，仍可聚焦、点击无效；原因写进隐藏的 `<span>` 并用 `aria-describedby` 关联，`title` 保留。
  - 无标签输入：跟进备注、回复草稿补 `aria-label`。
  - 读屏播报：设置表单底部错误、确认弹窗失败、事故组失败加 `role="alert"`；批量登记进度加 `role="status"`；七处复制按钮旁加共用的 `CopyStatus`（`role="status"`），复制后播报「已复制」；事故组认领全部/静默全部成功后用 `role="status"` 播报「已认领 / 已静默」。
  - 页面标题与跳转：切页时 `document.title` = `页面名 · Tono`；新增「跳到内容」跳转链接，`<main id="main" tabIndex=-1>`，切页（不含筛选、抽屉）后焦点移入 main，输入框或打开的弹窗内不抢焦点。
  - 抽屉/弹窗关闭后焦点回到打开它的按钮（Radix 没有 Trigger 时不会还，新增 `useRestoreFocus`，接在 `ui/dialog`、`ui/sheet`）。
  - 表头：可排序列加 `aria-sort`，箭头 `aria-hidden`。
  - 深色模式强调色文字（3.33:1）：新增 `--accent-text`（浅色同 `--accent`，深色 #8f84ff），用于「返回用量」、节点页链接、批量登记两个链接、商家「打开」链接、节点详情「登记额度」类链接、选中的筛选标签和导航选中项；白底按钮不变。
  - 关闭控件：`ui/dialog`、`ui/sheet` 写死的英文 Close 改用「关闭」；`DetailDrawer` 关掉重复的右上角关闭，补不可见的 `SheetDescription`，Radix 不再报缺描述。
  - 导航地标：侧栏 `aside` 不再带「业务导航」标签（只留 `nav`），底部 dock 改叫「底部导航」。
  - 可点整行（今天质量表、节点列表）：保留鼠标点整行，不加 `tabIndex`；行内名字链接已是键盘入口，再加一个 tab 停靠点会让每行两次停。
- 工程与测试：`Action.test.tsx`（aria-disabled、描述关联、屏蔽点击）、`DataTable.test.tsx`（`aria-sort`）；`Devices.test.tsx` 和 `ledger.spec.ts` 里按旧 `disabled`/重复文案断言的两处随契约改动；新增 `e2e/a11y.spec.ts`（跳转链接、键盘换页与标题、抽屉焦点往返、390 px dock 焦点环、被屏蔽动作的描述）。
- 验证（本机，`services/ops-console`）：`npm run -s typecheck`、`npx vitest run`、`npx eslint src e2e`、`npm run build`、Playwright 全量（`--ignore-snapshots`）见交付报告。
  截图：焦点环只在聚焦时出现，几乎不影响基线；深色强调色文字变色，节点页（批量登记链接）、商家 `providers`、节点详情的深色基线会变，本提交没有重录。
- 候选/发布：无新包，仅源码。
- 剩余限制：未做读屏软件（VoiceOver/NVDA）实测，播报行为按 ARIA 语义和 Playwright 的无障碍树断言验证；事故组的状态播报是动态插入前就存在的 `role="status"` 行，遇到不播报的读屏器需另测。
