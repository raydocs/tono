## 2026-10-31 · sing-box 桌面核心从 alpha.12 升到 alpha.13
- 归属：ops 计划（sing-box 分阶段，不是客户发布门）；macOS 安装针、Windows 安装针与打包门、CI 的 sing-box 校验。做法同 [#1686](https://github.com/raydocs/tono/pull/1686)，PR [#1809](https://github.com/raydocs/tono/pull/1809)。
- 来源：基线 main `372a4cc6c`；分支 `claude/singbox-alpha13`；未合 main。上游 `v1.15.0-alpha.13` / `824dbcfb4dd0a95921840b1737b950cde590241e`（2026-10-23），发布时为上游最新版。构建配方不变：Go 1.27.1、`CGO_ENABLED=0`、tags `with_gvisor,with_quic,with_utls,with_clash_api`、`-mod=readonly -trimpath`、无补丁。横幅 `1.15.0-alpha.13-tono-a13.1`。

- 新增/优化：alpha.12 与 alpha.13 的源码树差异约 130 个非文档文件，多为上游修复。与 Tono 相关（按源码树核对，不按上游提交列表，两个 tag 之间历史已改写）：sing-tun 升到 `v0.9.7-0.20261023115453-611d83b7a57b`（流分发 `flow_dispatch.go` 调整；Windows 新增 `tun_bind_windows.go`，处理 weak host 发送下的接口绑定；`tun_windows.go`、`monitor_windows.go` 有改动）；拨号器把网络命名空间传给慢速拨号、ICMP 改为按网络策略取控制函数，并行拨号文件有调整；DNS 客户端在命中缓存（含乐观缓存）时也执行响应检查；Reality 客户端对 IPv6 字面量服务器名的请求地址修正。删除了未实现的 `direct` 规则动作（Tono 的配置不使用）；VLESS `name` 与出站 `server_port` 改为可省略（现有配置不受影响）；clash API 监听按地址族选择网络。核对过仍然成立的版本假设：hysteria2 仍接受 `keep_alive_period`，FakeIP 实现目录无变化，go 栈缓冲上限 `stack_go_profile_default.go` 不变（发送 2 MiB、接收 4 MiB）。
