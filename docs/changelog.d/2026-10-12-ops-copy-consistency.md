  - 整机失联 → 失联（节点结论词、今天页分组）
  - 整机连不上 → 中控连不上这台机器（原因行；节点页「中控机现在连不上这台机器」同步成同一句）

  - 已处理 N 位客户 → 已完成 N 位客户（「已处理」只留给事故）
