Trigger: connect on the main dashboard, receive traffic, then open the tray flyout for the first time. `core/tray/flyout.rs:70` creates `/tray`, which runs `src/main.tsx`. Its `DOMContentLoaded` sweep calls `MihomoWebSocket.cleanupAll`; even a new renderer with no local instances invokes `clear_all_ws_connections` (`guest-js/index.ts:531–536`). The app-managed plugin clears the shared manager and cancels readers (`src/mihomo.rs:441–452`) without a terminal callback. The dashboard's socket/live state remains populated, so its missing-feed recovery does not run. Removing the startup sweep preserves existing feeds; subscription owners retain their per-socket teardown. This does not stop Core or change WFP/DNS/AI protection.
