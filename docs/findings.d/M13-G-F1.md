`DiagnosticsLogUploader.readSegment`（`tooling` 无；`apps/macos/Tono/Services/DiagnosticsLogUploader.swift`）在 scope 过滤后 `eligible` 为空时调用 `gzip`，空输入返回 nil，函数返回 nil。活文件的游标因此留在这块之前；备份路径把 nil 当成不可读，满 `unreadableBackupSweepLimit` 后跳到活文件开头，丢掉备份里尚未读到的当前 scope 行。触发：本地审计在登录或同意之前已写下至少 `readChunkBytes`（4 MiB）别的 scope 的行，或换账号 / 关闭再打开上传后游标因 scope 不符从 0 重读。同块里混有当前 scope 的行本来就能上传，见 `DiagnosticsLogOwnershipTests`。
