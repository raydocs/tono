The production commands at `tooling/scripts/core-helper/SelectiveFailOpen.swift:91` set BLACKHOLE without a gateway operand. Apple's [route parser](https://github.com/apple-oss-distributions/network_cmds/blob/97e27e6244c16d399bfeb254315ddc5828711c56/route.tproj/route.c#L826) therefore omits RTA_GATEWAY, and [XNU RTM_ADD](https://github.com/apple-oss-distributions/xnu/blob/f6217f891ac0bb64f3d375211650a4c1ff8ca1ea/bsd/net/rtsock.c#L548) rejects the message with EINVAL. DNS sinkholes cannot cover cached or literal addresses. The fix supplies same-family loopback gateways; the [loopback output path](https://github.com/apple-oss-distributions/xnu/blob/f6217f891ac0bb64f3d375211650a4c1ff8ca1ea/bsd/net/if_loop.c#L429) discards BLACKHOLE packets before delivery. General routes and strict protection are unchanged.
