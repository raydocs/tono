# 国内家宽测试包（给老板本人 / 国内测试者，2026-10-11）

目的：在**中国大陆真实家宽或手机网络**上，用**真实的 Mac / Windows 客户端**确认登录、连接、掉线恢复和手动解除保护。
这是 SHIP_PLAN G1/G2 的现场证据来源之一；代理不替你勾 G1/G2。

## 国内 VPS 能不能代替？不能
- 国内 VPS（云机房）只能补充“机房网络到中继 / Cloudflare 是否可达”，属于**组件证据**。它不是家宽：运营商对家宽和机房的
  DNS、SNI 过滤、UDP、路由都可能不同，也测不到客户端的登录界面、保护开关、睡眠唤醒和手动解除。
- 不需要、也不要为此购买或部署国内 VPS。真实家宽上的一台 Mac 或 Windows 电脑就够。

## 准备（测试者）
- 一台平时在用的 Mac 或 Windows 电脑，接在国内家宽（电信 / 联通 / 移动任一）或手机热点上；能恢复（有管理员权限，测完可卸载）。
- 一个**测试账号**（老板发放的限量测试邮箱；不要用个人主账号）。**不要把任何密码、验证码、账号邮箱发给任何人或写进报告。**
- Python 3.8+（只用于第 A 部分）。

## A. 现在就能做：网络路径探测（组件证据）
候选包还没出时先做这一步。它不需要账号、不装东西，只测网络路径：
1. 断开 Tono 和任何 VPN / 代理，用平时的网络。
2. 下载 [`tooling/ops/cn-acceptance/cn_acceptance.py`](../../tooling/ops/cn-acceptance/cn_acceptance.py) 一个文件，运行：
   `python3 cn_acceptance.py --label "城市 运营商 家宽" --carrier cmcc|ct|cu|other`（Windows 用 `py`）。
3. 把生成的 `tono-cn-acceptance-<时间>.json` 发回。文件里公网 IP 只保留 /24，无凭据。
- 报告里这部分写明“**组件证据**（公开中继 TLS / API 探测），不是客户端验收”。含义见 [cn-acceptance.md](cn-acceptance.md)。

## B. 候选包出来后：客户端验收（现场证据）
先在 [owner checklist](release-0075-owner-g1-g2-checklist.md) 里确认冻结候选的**源码 SHA 与安装包 SHA-256**，安装前核对哈希
（Mac：`shasum -a 256 <文件>`；Windows：`certutil -hashfile <文件> SHA256`）。哈希不一致就停止，不要测。

每步记 `PASS` / `FAIL` / `UNKNOWN`、发生时间（北京时间到分钟），失败时截图（截图里遮住邮箱）并在 App 里「复制给客服」的内容一起附上：

1. **首次登录**：不开任何 VPN，打开 Tono → 输入测试邮箱 → 收到验证码 → 登录成功。记录用时（秒）。
2. **连接**：选默认城市连接 → 显示 Connected → 打开 2–3 个常用网站（境外站点）能访问。
3. **稳定**：保持连接 5 分钟，仍是 Connected。
4. **掉线恢复**：关 Wi-Fi 10 秒再打开（或合盖睡眠 1 分钟再唤醒）→ 记录 App 显示什么（重连 / 保护中 / 失败），1 分钟内是否自动恢复。
   掉线期间普通网站应**打不开**（保护生效），而不是直连。
5. **手动解除保护**：在保护中或连接中，点「断开」或「恢复网络」→ 确认提示 → 普通网站能直连打开。
   Mac 再跑 `scutil --dns | head -20`（不应是 127.0.0.1），Windows 跑 `nslookup example.com`（应是系统原 DNS）。截图。
6. **再次连接**：再点连接，能连上。

## 这份报告能证明什么、不能证明什么
- A 部分只证明该网络到中继 / Cloudflare 的路径；B 部分才是该网络 + 该候选包的客户端结果。
- 一个城市一个运营商只代表那一行；三网结论需要分别测。没有 B 部分就不能说“国内可用”。
