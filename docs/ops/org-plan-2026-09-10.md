## 0.6 这台 Mac 的容量（老板要拍板）

机器 12 核 / 18 GiB，今晚只有总监 + D 经理 + 两个 Grok 时交换区已用 7.1 / 8 GB。五个 Fable 会话各带 Grok/Opus 子代理、每个任务尾巴跑一次 Playwright 全量，会把机器推进交换抖动，Playwright 的 60 秒 webServer 超时会成为最常见的「红」，反驳者会把它当代码问题去修。两个选择：

- **A 方案（推荐）**：A、D 两个部门开成 **cloud 会话**（Worker 为主，只跑 vitest；实现用 Opus/Sonnet，因为 Grok CLI 只在本机），B、C、E 本机（需要 Grok、Playwright、客户端构建、wrangler）。本机同时最多 3 个部门。
- **B 方案**：五个都本机，但 Grok ≤3、Playwright 全量全机串行、任务级只跑自己 spec；接受慢。

## 5. 经理的 ultracode 模板（每个任务一个 workflow）

```js
export const meta = {
  name: 'dept-task',
  description: 'understand → implement → wait for the real exit → refute ×3 → fix → verify (task-level)',
  phases: [{ title: 'Understand' }, { title: 'Implement' }, { title: 'Refute' }, { title: 'Fix' }, { title: 'Verify' }],
}
const { brief, worktree, kind, ownSpecs, ownTests, port } = args   // kind: 'grok' | 'opus'
phase('Understand')
const map = await agent(`Read ${brief} and the files it names under ${worktree}. Return files to touch, files NOT to touch (docs/ops/org-plan-2026-09-10.md §2/§3), contract fields needed (all optional), tests to add.`, { schema: MAP })
phase('Implement')
if (kind === 'grok') {
  // grok returns early; the wrapper below only returns after the log shows "# grok-task exit="
  await agent(`Start ~/.claude/scripts/grok-task.sh --cwd ${worktree} --prompt-file ${brief} --timeout 7200 in the background, then wait until its log under ~/.claude/grok-runs/ contains "# grok-task exit=". Return the tail of the log.`, { label: 'implement:grok' })
} else {
  await agent(`Implement ${brief} in ${worktree} …`, { model: 'opus', label: 'implement:opus' })
}
phase('Refute')
const votes = await parallel(['correctness', 'contract-and-ownership', 'tests-actually-prove-it'].map(lens => () =>
  agent(`Lens: ${lens}. Read git diff in ${worktree} against ${brief}. Refute correctness/completeness; refuted=true if uncertain.`, { schema: VERDICT, label: `refute:${lens}` })))
const problems = votes.filter(Boolean).filter(v => v.refuted)
phase('Fix')
if (problems.length) await agent(`Fix in ${worktree}: ${JSON.stringify(problems)}. Narrowest test each.`, kind === 'grok' ? { agentType: 'grok' } : { model: 'opus' })
phase('Verify')
return await agent(`In ${worktree}: Worker → npx vitest run ${ownTests}; console → OPS_CONSOLE_PORT=${port} npx playwright test ${ownSpecs} --workers=2 (kill by port first: lsof -ti :${port} | xargs -r kill), plus typecheck+lint. Paste raw output. Do not edit code.`, { schema: VERIFY, effort: 'low' })
```

经理在 workflow 之外：写 brief、亲自读 diff、合到 `dept/<x>`、开 dept PR 前跑一次全量（加锁）、发状态。
