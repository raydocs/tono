## 2026-10-12 · Replace every Tono icon with the sun-on-the-horizon artwork
- Status: provisional (the owner can set `owner`; Line in chat, 2026-10-12, after seeing the brand sheet `apps/windows/app/src/dev/sea-shell/brand/approval-sheet.png`: "图标都得换 mac 的换了么看一下" and "做图标然后 mac 和 win 的都替换", then "继续换掉 mac 菜单和托盘新图" and "别还是通用盾牌图标 换别的")
- Chosen: the sheet's artwork replaces the "TO" gradient mark everywhere it ships: the Windows app, installer and tray icons, the NSIS header and sidebar bitmaps, the in-app logo and first-paint mark, the welcome hero, the macOS app icon, in-app mark and welcome hero, and the release centre favicon. The macOS menu bar and the Windows tray draw their states with one sun-on-the-horizon glyph family, mapped one to one onto the states they already report (macOS six: `MenuBarProtectionStatus.Kind`; Windows three: `tray_icon_kind`). Only a verified connection gets the filled sun; standby, connecting and unknown are an open arch (connecting broken, unknown badged), protected offline adds a slash, degraded is the filled sun with a badge. Shape alone carries state because the macOS status item is a template image. Rejected: the 2026-10-06 draft four-state tray sheet (`tray-icons.svg`, deleted); its states (connected / connecting / protected / idle) do not match the states either platform reports, so wiring it would change what the tray says, not only how it looks.
- In-app shields: no generic shield symbol remains in either app. Where a view shows protection state it uses the same `MenuBarStatus*` glyphs (macOS gate notice); where it meant something else it gets that thing's own symbol (account problem, catalog check, secure DNS network, diagnostics document, retry). Windows drops the `shield`/`shieldCheck` icons for a stroked sun-on-the-horizon (Tono's own exits) and a pulse (health check).
- Why stricter: presentation only. No connection, protection, routing, privileged or update-trust behaviour moves, and no state is merged or split: each glyph replaces the symbol of exactly one existing state. The PR is a UI change: it merges only after the owner checks the before/after screenshots, and native rendering (Windows taskbar and installer DPI, Finder and Dock) still needs a look on real machines.
- Applied in: PR `claude/sun-horizon-icons` (`apps/windows/app/scripts/generate-tono-icons.py` regenerates every raster from the sheet).
