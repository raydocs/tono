## 2026-11-27 · Hysteria 2 Brutal stays default BBR with per-node opt-in down-mbps

- Status: owner
- Chosen: leave `up_mbps` and `down_mbps` unset by default on `sing-box` Hysteria 2 outbounds (so both directions use adaptive QUIC + BBR via `sing-quic`), admit an optional bounded integer `down-mbps` (`10..=500`) on ` · hy2` catalog blocks for nodes with lossy return paths, and add `manage-tono-hy2-node.sh set-bandwidth` (`ignoreClientBandwidth` / `up` / `down`, server cap `10..=1000` Mbps; values `>500` are server-only and cannot be advertised in desktop catalogs) so server-side Brutal can be switched off immediately per node (`--ignore-client-bandwidth true`). Client `up_mbps` is never admitted or emitted; Mihomo fallback strips `down-mbps`. Rejected: hardcoding global `up_mbps: 50 / down_mbps: 200` on every desktop HY2 outbound, which would overshoot 10–40 Mbps uplinks and cellular hotspots under Brutal fixed-rate pacing.
- Why stricter: default behavior widens zero congestion surface; `down-mbps` is bounded (`10..=500`), restricted to unquoted block-style YAML on ` · hy2` entries only (ignored by legacy `0.0.88` clients; quoted/flow/VLESS/`up-mbps` forms refused by publisher and Worker), never sets `up_mbps`, and leaves Helper protocol (`HelperProtocolVersion`) and kill-switch boundaries untouched. Before enabling any node beyond canary (`HY2_CATALOG_EMAILS`): lower server `--up-mbps` conservatively first, benchmark Mesa A/B with both a bandwidth-shaped (~20 Mbps) client and multi-client contention, and note that `set-bandwidth --ignore-client-bandwidth true` is the immediate cross-platform emergency lever (it restarts `tono-hy2`, dropping active hy2 sessions while leaving `tono-xray` untouched; catalog removal triggers a macOS reconnect on next sync via `liveSessionIdentity` whereas connected Windows sessions keep the prior hint until reconnect).
- Applied in: `services/control-plane/src/catalog-yaml.ts`, `tooling/scripts/publish-managed-catalog.rb`, `apps/windows/crates/tono-core/src/{node.rs,config.rs,sing_box/runtime.rs}`, `apps/macos/Tono/{Models/ProxyNode.swift,Services/ConfigParser.swift,Core/Configuration/ConfigPipeline+Nodes.swift,Core/Configuration/ConfigPipeline+SingBoxProduct.swift}`, and `tooling/scripts/remote/manage-tono-hy2-node.sh`.
