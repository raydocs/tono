## 2026-10-17 · What safety boundaries remain while implementing desktop three-tier routing?

- Status: provisional. The owner requested AI/Home-group → Home, other identified domestic → DIRECT and overseas → cloud, and explicitly retained the existing named Home group (including non-AI services) and the 21 cloud-video exceptions. This records the stricter implementation boundaries, not approval of the three previously unanswered availability/unknown/DNS alternatives.
- Chosen: preserve the existing specific video exceptions before the named Home group, then classify other supported domestic/overseas traffic. Do not infer non-AI identity from a CN address or absence from an AI list. Unclassified traffic in the new mode is refused, not DIRECT or a silently weaker Home identity. Core/privileged-component death or loss of trusted classification keeps the new mode fail-closed; ordinary-network independence applies only while Core remains healthy. Explicitly ending protection uses the separate existing release contract. Keep the fixed reviewed DoH/TLS requirement, with Home DNS through cloud → assigned Home, rather than substituting an unreviewed supplier resolver. No change to the old mode's current runtime or automatic recovery is made by this decision.
- Why stricter: shared CDN, cached IP, custom DoH and ECH prevent a country list or PF/WFP AppId from proving arbitrary service identity. Sniffing and configuration scans may narrow uncertainty but are not a guarantee. Legacy GeoIP downloads/files are not a trusted update channel. Begin with reviewed, versioned bundled classification; no remote updates or broader physical/IPv6/UDP permit is implied. Mac root permits and Windows process authorization must not bypass the same protected-destination contract.
- Applied in: [#1571](https://github.com/raydocs/tono/pull/1571), [current contract and implementation sequence](../reports/smart-routing-nightly-2026-10-11.md). Desktop only; 0.0.76 RC, stable feeds and mobile repositories stay unchanged. No new candidate, merge or publication is authorized. Current product implementation and installed-device qualification are not complete.
