# Tono 0.0.66

Build 66 is Build 65's code, published from Tono's own repository rather than a fork of
someone else's. Nothing about routing, the kill switch or the app itself changed; if you
are on Build 65 you already have every fix this contains, and the update is worth taking
only so that later ones reach you from the place they will keep coming from.

- The download and update addresses now point at Tono's own repository. Build 65 was
  published from a fork, and everything it linked to lived under that fork's name.
- The Windows side of the same release moved with it, and its update check no longer goes
  to an address blocked from mainland China. That does not affect this build; it is the
  reason the pair moved together.

The privileged helper is unchanged at 3.12.2, so this update does not ask for an
administrator password.
