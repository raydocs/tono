# 0.0.88 · Build 89
> Apple Silicon、macOS 26.3+。本版重点修复节点切换失败整条断开与回滚问题、误报无法验证连接、Helper IPC/更新退役卡死与 PF 探针缺陷，并持续打磨 Tahoe 液态玻璃界面与交互细节。

- 节点切换回滚与连通性分类修复（#1868）：切换节点失败时优先原位回滚至原节点不断开现有保护；补充 utun 接口与本地 DNS 就绪校验；在 TUN 失败诊断期间绕过延迟门控，避免不可达节点被误判为链路不可用；Strict（严格）模式下已连接时阻止在线切换或重载并恢复清晰中文提示
- Helper 与网络恢复加固（#1866、#1867、#1868）：Helper 协议升级至 `4.52.78`，支持启动中断期间经校验后的回滚同步；区分空 anchor 与不可读 PF 状态、独立更新退出栅栏并清理抢占式恢复后的重复操作按钮；增加 Helper IPC 空响应受控重试；修复更新退役与外部释放后的 `helperSession` 及卡在登录页的挂起更新报错
- 界面与交互优化（#1868）：优化主界面、节点页、菜单栏、侧边栏与登录页的液态玻璃边框对比度、按钮悬停/弹性触感、数字等宽排版、节点切换中指示器及降透明度/高对比度无障碍回退

## 时间线
修复切换失败与连接验证体验痛点，升级 Helper 至 `4.52.78`，并优化 macOS Tahoe 界面视觉层级与交互反馈。

## 限制
- 仅 Apple Silicon，需 macOS 26.3 或更高
- IPv6 全程关闭：TUN 与 fake-ip 只走 IPv4，AAAA 拨号由 Kill Switch 丢弃后客户端改试 IPv4
