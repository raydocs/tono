# Tono 0.0.83 — 客户手动测试 RC（build 84）

这是替代 0.0.82 RC（build 83）的手动安装测试候选，不是稳定验收。正式更新源不变。需要 Apple Silicon 与 macOS 26.3+。

build 83 之后新增：

- **修复：登录时提示「连不上任何一台中继」**（#1836）。中继列表改为两个地址：Westwood 的新 IP 和 Mesa，去掉被封的旧 Westwood 地址和 Arosscloud 中继。没有隧道时（首次登录、重新登录、刷新令牌）Tono 只通过这些中继访问控制面，所以旧 Westwood 地址被封、Mesa 又连不上的网络就进不去。网络辅助程序升到 4.52.71，放行新的中继地址；旧辅助程序更新前仍放行旧地址。
- 0.0.82 的内容全部保留。

## 安装与必须测试的项目

先核验发布的 SHA-256。在旧 Tono 里选择「恢复正常网络」，确认普通上网正常，退出后用已签名公证的 ZIP 替换 `/Applications/Tono.app`。只批准正常的 Tono 辅助程序安装（本版把它更新到 4.52.71）。不要手动删除辅助程序，也不要绕过保护或安装的拒绝；恢复或批准失败就停下并联系支持。

确认辅助程序显示 4.52.71。在旧版提示连不上中继的网络里，先不连接 Tono，退出登录再重新登录，确认能登录。然后重做 build 83 的测试项（AI Home、稳定、三层分流、防泄漏）。记录新旧版本、安装包哈希、系统和结果。云端 CI 不等于真机验收。

## 已知限制

- 没有隧道时登录仍只走这两个中继；两个都连不上的网络仍会登录失败（决定 091）。旧版安装会一直带着被封的地址，直到更新，所以登不上的客户首次登录要手动安装本版，或换一个网络（手机热点）。
- 0.0.82 的限制仍然有效：防泄漏规则未在真机实测；G1–G3、旧版升级和真实 PF/DNS 故障未验收。失败的候选不能靠覆盖安装旧版回退，请联系支持。
