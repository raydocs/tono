# Tono 0.0.77 — 客户手动测试 RC（build 78）

这是手动安装测试候选，不是稳定验收通过。正式更新源、旧 0.0.76 RC 均不变。仅支持 Apple 芯片及 macOS 26.3+。

- 设置新增可选“三层分流”；默认仍是稳定模式。保存后须显式断开再连接，自动恢复保留当前会话模式，不消费刚保存的下次设置。
- 顺序为：21 项视频云例外 → 原 166 项 AI/具名 Home 经云到原 assigned Home → 明确云名单 → 其他受支持普通流量 DIRECT（含未分类）。已识别 Home/云端解析或拨号失败不降级直连，固定 DoH 和 Core 死亡阻断保留。
- 普通 DIRECT 仅支持公网 IPv4 TCP80/443；业务 UDP/QUIC、IPv6、LAN 和其他普通端口未支持。ECH、缓存/裸 IP、自带 DoH 可能隐藏 AI 身份而默认直连，不能保证任意未知 AI 都走 Home。Home 组含具名非 AI 服务，不是完整 AI 分类库。
- 修复晚解析进入已知 Home CIDR 却直连，以及自动恢复错误消费下次模式。三层期间禁用 LAN，但保留稳定模式原偏好。模式/规则/云节点变更须显式断开重连，不热切换。

## 安装与必须测试的项目

先核验发布的 SHA-256。旧 Tono 选择“恢复网络”，确认普通上网正常，退出后通过已签名/公证的 DMG 或 ZIP 替换 `/Applications/Tono.app`，只批准正常 Tono helper 安装。不要手删 helper 或绕过保护/安装拒绝；恢复或 helper 批准失败就停止并联系支持。

先测稳定模式，再显式开启三层：连接/Activity、真实 DNS 与云/Home/直连出口、换云后 Home 身份、Home/云故障、Core/helper 死亡、重启、显式恢复、睡眠/唤醒和换 Wi-Fi。记录旧/新版本、包摘要、系统与结果；托管 CI 不是真机验收。

## 已知限制

- #1071/#1504 中止 helper 升级的 AI hold 风险独立保留，#1605/#1643 未包含；不能把中断升级或受保护自动更新称为已验证。PF root UID/NIC 范围不是 PID 隔离；无 helper 启动前开机出口保证。
- G1–G3、旧客升级、真实 PF/DNS 故障、Home 第二跳身份及固定候选试用尚未验收。失败回退不能直接覆盖安装旧版，请向支持索取兼容恢复方案。
- 保留已有日志偏好；新安装默认上传网络日志，可在设置调整。日志可能含域名和应用名，不含页面内容或密码。
