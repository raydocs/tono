# Tono 0.0.69

Build 69 修了国内网络下受保护验证失败的问题。

- 数据面探测不再走系统 URLSession 的 DNS。每个探测先问 `127.0.0.1:53`，必须拿到 `198.18` 假 IP，再对这个地址做 TLS（SNI 仍是原域名）。加密 DNS 和污染缓存不能再把探测绕出隧道，然后被 PF 丢掉。
- mixed 交叉检查改为对主机名发 HTTP CONNECT，同样不走系统解析。
- 网络助手仍是 3.13.0，这次不会再要管理员密码。

探测来源仍是 Google、Cloudflare、Apple，任一成功即可。控制器 `/delay` 仍然只作提示。
