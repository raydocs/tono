# Tono 0.0.68

Build 68 不再因为某一个健康检查网址失败，就把已经可用的隧道拆掉。

- 连接不再把 Mihomo 的 `/delay` 当成能否连通的证据。只有经过锁定 TUN 的真实 HTTPS 才能进入已连接。
- 数据面同时探测 Google、Cloudflare、Apple，任一成功即可；单个来源故障不会让整次连接失败。
- 可选 DIRECT 策略改到已连接之后再应用，第一次锁定不再被这次改写拖住。
- 切换节点会先验证新出口；新路径不可用时回退，不再重启核心。
- 网络助手升级到 3.13.0：受保护 DNS 走 System Configuration，`networksetup` 只作回退。这个版本第一次启动会要一次管理员密码。

这是和 Windows 0.0.35 一起给你测的候选版本。
