# Tono 0.0.73

这是第一发可发布切。**本版备用通道仅手动。** Tono 不会自己切过去。

- 默认路径一键连接，带城市名。连上之后，仪表盘和活动应停在已连接。如果又跳回重试，把诊断块复制发过来。
- 某个城市连不上或连不稳时，可以自己选 **备用通道**。不会自动打开，也不是每个账号都能看见。
- 连接失败时主界面是一句短原因。支持页可以复制失败阶段和错误码，用来报修。
- 网络 Helper 为 3.16.0。已装机器会要一次管理员密码来替换。
- 没有手机端，没有 Linux 端。macOS 14+。
- 睡眠唤醒未认证。醒后若会话没回来，再连一次。
- Mac 真机上的第一次应用内更新仍未证实。在确认之前请留一条回到 0.0.72 的路。

## 已知限制

源码测试和 CI 不能代替实机安装。不承诺所有网站、所有银行 3-D Secure、所有 Secure DNS 都能过。

- [#17](https://github.com/raydocs/tono/issues/17)：未覆盖全部浏览器 Secure DNS、银行 3DS 和登录后支付。
- [#26](https://github.com/raydocs/tono/issues/26)：完整受保护自动更新仍未证实。手动安装请先正常断开并退出 Tono。
- [#4](https://github.com/raydocs/tono/issues/4)、[#5](https://github.com/raydocs/tono/issues/5)：计量不在这一发桌面切里。
