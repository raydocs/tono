# Tono 0.0.84 — 客户手动测试 RC（build 85）

这是替代 0.0.83 RC（build 84）的手动安装测试候选，不是稳定验收。正式更新源不变。需要 Apple Silicon 与 macOS 26.3+。

build 84 之后新增：

- **修复：在会按 TLS 名称重置 `api.afk.ccwu.cc` 的网络里仍然登不上**（#1838、#1839）。这类网络里到中继的 TCP 能连上，但握手按名称被重置。现在经中继访问控制面时，Tono 改用 `static.bicon.dev` 这个名称，它指向同一套 API，两台中继都放行。只有中继这条路径换名：隧道已运行、固定地址和更新下载仍用原来的域名；网络助手不变（它按地址和端口放行中继）。
- 0.0.83 的内容全部保留。

## 安装与必须测试的项目

先核验发布的 SHA-256。旧 Tono 选择「恢复网络」，确认普通上网正常，退出后用已签名公证的 ZIP 替换 `/Applications/Tono.app`。不要手动删除助手，也不要绕过保护或安装被拒的提示；恢复或助手授权失败就停止并联系支持。

在 build 84 提示连不上中继的网络里，先不连接 Tono，退出登录再登录，确认能登录。然后重做 build 84 的测试项。记录新旧版本、安装包哈希、系统与结果。托管 CI 不等于真机验收。

## 已知限制

- 没有隧道时登录仍只走这两个中继（决定 091）。如果某个网络把 `static.bicon.dev` 也封了，就需要再换名称；旧版安装（含 build 84）仍用旧名称，所以这样的客户首次登录要手动安装本版，或换一个网络（手机热点）。
- 检查更新和下载仍使用 `releases.afk.ccwu.cc`。
- 0.0.83 的限制仍然有效；G1–G3、从更旧版本升级和真实 PF/DNS 故障未验收。失败的候选不能靠覆盖安装旧版回退，请联系支持获取兼容的恢复方式。
