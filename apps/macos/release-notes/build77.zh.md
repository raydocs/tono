# Tono 0.0.76 — 客户测试候选（build 77）

这是全新制作、手动安装的测试候选，不是已通过真机验收的稳定版。正式自动更新源保持不动。

- 包含已合入主线的独立「恢复正常网络」组件、Wi-Fi DHCP/邻居发现恢复及当前客户端/工具链修复；不包含 HOLD 或设计尚未放行的分支。
- 需要 Apple 芯片、macOS 26.3 或更高；没有 Intel、iOS 或 Linux 安装包。
- 先下载并核对公布的 SHA-256。在旧 Tono 中点 **恢复正常网络**，确认普通互联网可用，再退出 App。用候选替换 `/Applications/Tono.app`，只批准正常的 Tono Helper 安装请求。不要手动删除特权 Helper，也不要强行解除未知保护。
- 手动覆盖安装是本次测试路径，不等于受保护自动升级已通过。恢复、替换或 Helper 授权失败时，保留准确报错交给支持人员；保护未知时不要反复重试。
- 请测试连接、活动、断开后 DNS 恢复、热点切 Wi-Fi、恢复后两分钟不复锁、重启与睡眠唤醒；记录旧版本、候选哈希、系统版本和结果。

## 已知限制

- 真机与旧版本升级仍待验证；本版没有修复中止 Helper 升级丢失 AI hold 的 [#1071](https://github.com/raydocs/tono/issues/1071)。取消 Helper 替换不能当作保护已验证。
- 新恢复组件不代表旧系统代理清理或手动紧急命令也已验收。
- 保留原有日志偏好；新安装默认上传网络日志，可能含主机名和程序名，不含页面内容或密码，可在设置关闭。
- 安装失败时不要直接覆盖降级，请联系支持人员选择恢复路径。
