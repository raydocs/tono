# Tono 0.0.70

这版把界面上和事实对不上的地方都改了：显示的数字、国旗、计数和实际情况对不上。连接和路由的行为没有改动。

0.0.69 里那批国内网络的探测修复继续保留（探测不再走系统 DNS，先拿假 IP 再做 TLS）。

- 延迟以前只在连上的那一刻测一次，测到的是冷启动握手的值（常见八九百毫秒），然后整个会话都不再更新。现在会持续重测；切换节点后也会立刻重测，不再拿上一个节点的数字充数。首页和节点页现在用同一种方式查同一个节点。
- 首页胶囊以前用毫秒，下面的卡片用秒；现在都用秒。
- 活动页的上传下载速率以前恒为 0，首页却有数字。现在两边同源，读不到就诚实显示「—」，不再拿 0 冒充。
- 连接列表的国旗以前用路由名做子串匹配，家宽流量被判成德国、微信连腾讯被判成印度。现在按整词匹配。
- 「活动连接」的计数以前含被隐藏的本机 DNS，显示 104 而列表只有四十条。现在和列表同源。
- 连接列表以前不排序就截断，「最新 2000 条」可能恰好丢掉最新的；现在按开始时间排序。
- 日志页以前只在停留在该页时才收日志，中途打开会显示 0 条记录。现在会一直缓冲。
- 未测速的节点显示「未测速」，不再是破折号；同一张卡片不再出现两种说法。
- `JP-VLESS-Reality` 现在显示成东京并带城市图标；洛杉矶那个节点两端统一叫 Grove。
- 切换节点的提示和活动页的出口名改用本地化城市名，不再中英混排。
- 规则页不再直接打印 DIRECT、REJECT 这类内核术语。
- Claude Code 在应用列表里有图标了。
- 中文统一：一律说「节点」，活动页的路线名与筛选、图例同词，断网保护的说法从「阻断」改为「拦住」。十几条以前会显示英文的字符串补齐了中文。

探测来源仍是 Google、Cloudflare、Apple，任一成功即可。控制器 `/delay` 仍然只作提示。
