# 0.0.66 · Build 66
> Apple Silicon、macOS 26.3+。代码与 Build 65 完全相同，区别只在于它发布自 Tono 自己的仓库，而不是别人项目的一个 fork。路由、Kill Switch、应用本身都没有改动——你如果已经在 Build 65，该有的修复都已经有了；升级的意义只是让之后的更新从它们将长期所在的地方送达。

- 下载与更新地址改为指向 Tono 自己的仓库。Build 65 发布自一个 fork，它链接到的一切都挂在那个 fork 的名下
- 同一轮里 Windows 也一起搬了，并且它的更新查询不再走在中国大陆被屏蔽的地址。这一点不影响本版，但正是两个平台一起搬的原因
- 特权 helper 仍是 3.12.2，本次更新不会要求输入管理员密码

## 时间线
Build 65 的代码，改从 Tono 自己的独立仓库发布。此前的仓库是别人项目的 fork，所有下载与更新地址都挂在那个名下；同一轮 Windows 也一起迁移，并把更新查询从被屏蔽的地址挪到了自己的服务器。应用本身没有任何改动，helper 仍为 3.12.2，升级不需要输入管理员密码。

## 限制
- 仅 Apple Silicon，需 macOS 26.3 或更高
- IPv6 全程关闭：TUN 与 fake-ip 只走 IPv4，AAAA 拨号由 Kill Switch 丢弃后客户端改试 IPv4
