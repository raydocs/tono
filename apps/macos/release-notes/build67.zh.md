# 0.0.67 · Build 67
> Apple Silicon、macOS 26.3+。本次是界面的整体重做、完整的简体中文本地化，以及一个重要的账户修复。

- 全应用中文化：每个界面、每条错误信息、菜单栏，包括启动时网络组件报告的错误
- 登录页重新设计：更干净的欢迎页，邮箱与 Apple 登录并排，六位验证码输满自动提交，错误信息可读并补上了缺失的"重试"按钮
- 账户设备数达到上限时，登录页会直接列出你的设备并允许当场移除——此前它让你去一个根本进不去的页面处理
- 节点按城市命名（洛杉矶、东京、盐湖城……），每个城市有自己的地标图标——棕榈、鸟居、天守阁、雪山盐湖、瀑布——不再是一排一模一样的条目；列表随窗口宽度自动排列
- 深色模式改为真正的黑玻璃质感；状态颜色、延迟分档、强调色在所有界面保持一致
- 连接控件显示所选城市与延迟，隧道建立时 Tono 标志会点亮；首页会标出你的 AI 流量（Claude、ChatGPT、Grok）所走的家宽线路
- 切换节点、导出日志有轻提示确认；测速结果逐个滚动出现；动效遵循"减弱动态效果"设置

特权 helper 没有变化，本次更新不会要求输入管理员密码。
