# Tono 0.0.71

这版重点修复连接稳定性，并确保每个账号的受管节点凭据彼此隔离。

- 受管节点目录改成一次只刷新一个请求。旧响应不会再晚到并覆盖较新的路由或账号凭据。
- 目录更新会等正在传输的代理流量结束再应用；内容没变就不重载。日常节点增删不再因为目录版本变化而中断正在进行的请求。
- 缓存目录现在绑定到收到它的账号，退出登录时会清除。同一台 Mac 上的下一个用户不会继承上一个账号的节点身份。
- 数据通道失效时会执行一次受断网保护约束的修复，不再永远卡在「正在恢复」。修复失败后会明确结束本次连接，用户可以重试。
- 网络助手升级到 3.13.1。PF 规则如果只提交了一部分，下一次启用会执行保守的完整状态清理，不再信任未完成的规则代次。已有安装会再请求一次管理员密码来替换助手。
- 切换语言时会等旧进程完成 DNS 和防火墙恢复后再重新打开；如果当前仍有保护，会先提醒用户。
- 未签名的受管策略不能再把任意公网地址绕到隧道外。上传诊断也会隐藏进程路径里的账号名，不再包含异常原文和原始返回地址。

控制面暂时不可用时仍保留最后一份验证通过的目录；Tono 不会降级成无保护连接。
