# Tono 0.0.82 — 验收测试 RC（build 83）

这是替代 0.0.80 RC（build 81）的手动安装测试候选，不是稳定验收通过。build 82（0.0.81）构建过但没有发出，它的内容也一并列在这里。正式更新源不变。仅支持 Apple 芯片及 macOS 26.3+。

build 82 之后新增：

- **修复：稳定、三层分流和 AI 家宽下，部分流量可能绕过隧道**（#1820）。桌面分流现在带上和移动端相同的防泄漏规则：DNS-over-TLS（853 端口）、STUN（含 IPv6）、海外 UDP、DNS HTTPS/SVCB 查询、家宽辅助域名和 X 的域名（`grok.x.com` 仍走家宽）。AI 家宽里每条家宽 TCP 路由都配上对应的 UDP 拦截。网络助手升到 4.52.69 以带上这些规则；旧助手在更新前保持旧规则。
- **修复：hy2 连接失败后跳过了同一节点的另一种传输**（#1797）。`X · hy2` 拨号因 QUIC 或登录以外的原因失败时，Tono 先试 X 自己的 Reality 块，与 Windows 一致。
- **空闲时少重绘**（#1798）。连接卡片只在显示计时或重试倒计时时才每秒刷新。

同时包含 build 82 的内容（#1760、#1767）：

- 所选节点没应答时会直说，仪表盘提供「选择其他线路」。
- 两种助手拒绝会说明原因：系统 DNS 还没进入保护路径（稍等再连），连接引擎刚启动就退出（重新连接，重复出现时发送诊断）。
- 「流量没能进入隧道」会写明哪项检查失败、当时在运行的其他 VPN；每次连接最多重新武装隧道三次。
- 连接失败最多提前 5 秒给出结果；自动重连同时测试所有候选节点，首选节点能应答时仍优先。
- 0.0.80 的内容全部保留：家宽线路给网关域名时 AI 家宽与三层分流可用；AI 名单 194 条。

## 安装与必须测试的项目

先核验发布的 SHA-256。旧 Tono 选择「恢复正常网络」，确认普通上网正常，退出后用已签名/公证的 ZIP 替换 `/Applications/Tono.app`，只批准正常的 Tono helper 安装（本版会把 helper 升到 4.52.69）。不要手删 helper 或绕过保护/安装拒绝；恢复或 helper 批准失败就停止并联系支持。

AI 家宽、稳定与三层分流照 build 81 的清单测。本候选另加：安装后确认 helper 显示 4.52.69；三种模式下各做一次 WebRTC/STUN 泄漏测试和 DoT（853）查询，确认看不到本机 IP 或本地解析器，`grok.x.com` 仍从家宽出口；选一台 UDP 被挡的 `X · hy2` 节点，确认 Tono 用 Reality 留在 X 上，而不是换到别的节点。build 82 的测试项照做：挂掉的节点提示换节点、出现「选择其他线路」；失败时点名其他 VPN；诊断的 TUN 路由那行写明失败的检查。记录旧/新版本、包摘要、系统与结果；托管 CI 不是真机验收。

## 已知限制

- 防泄漏规则（#1820）在代码上与移动端合同一致，尚未在真机 Mac 上实测；四台线上出口的 Reality/TCP 配置只在仓库里钉住，没有重新测量。
- 隧道锁定后，节点死了和本机隧道坏了仍是同一个码；运维侧靠同一节点上失败的客户数来区分。
- 助手不会把连接引擎自己的日志传给应用，「引擎刚启动就退出」只带退出状态；其余靠发送诊断。
- AI 家宽的保护范围是已收录的 AI 名单，不是所有 AI 服务；普通流量不过滤。Clash 等其他 TUN 与 Tono 并存时仍只在失败后点名，没有连接前检查。
- #1071/#1504 中止 helper 升级的 AI hold 风险独立保留，#1643 未包含。PF root UID/NIC 范围不是 PID 隔离；无 helper 启动前开机出口保证。
- G1–G3、旧客升级、真实 PF/DNS 故障、Home 第二跳身份及固定候选试用尚未验收。失败回退不能直接覆盖安装旧版，请向支持索取兼容恢复方案。
- 保留已有日志偏好；新安装默认上传网络日志，可在设置调整。日志可能含域名和应用名，不含页面内容或密码。
