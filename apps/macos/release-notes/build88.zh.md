# 0.0.87 · Build 88
> Apple Silicon、macOS 26.3+。本版修复了 macOS 应用内更新退出失败、未保护状态更新失败误装 AI 黑洞、以及手动覆盖安装卡死等问题，并补充了本地失败诊断日志。

- 应用内更新退出与网络保护修复（#1860、#1862、#1863）：修复 SwiftUI `AppDelegate` 查找为空导致更新无法退出的根因，超时后由执行器结束卡住的原进程，允许已消费但中止的更新立即清理，并保证未开启保护的机器更新失败时不再误装 AI 黑洞
- 手动覆盖安装恢复与本地诊断（#1859、#1861、#1864）：允许在挂起更新状态下手动拖入更新版本的签名 `Tono.app` 后通过恢复网络正常解除，完善挂起更新提示，将登录/连接/更新失败分类报告持久化到本地日志，并为流量策略拒收补充本地诊断事件
- Helper 协议版本升级至 `4.52.76`

## 时间线
修复 macOS 应用内自更新退出失败与更新失败误拦截 AI 网络问题，并支持手动覆盖新版后直接恢复。

## 限制
- 仅 Apple Silicon，需 macOS 26.3 或更高
- IPv6 全程关闭：TUN 与 fake-ip 只走 IPv4，AAAA 拨号由 Kill Switch 丢弃后客户端改试 IPv4
