# Tono 0.0.63

- WeChat now stays on the direct path. Its main channel runs on port 80, and that port was being sent through the protected exit — so on a connection from China, WeChat's traffic to Chinese carrier servers was making a round trip to the United States and back. That is the delay and the spinning that was reported. Two logs from one account showed 82% and 72% of WeChat's connections leaving through the exit; both now go direct, with the exit still there as a fallback if the direct path fails.
- Activity is rebuilt. It opens on a per-app view: every app that has used the network this session, sorted by traffic, with a bar showing how much of it went direct, how much through the residential exit, and how much through the tunnel. The old connection list is still there under Connections. Above both, cards for exit latency, upload and download rates, active connections, and the session's traffic split by route.
- The exit row on the Dashboard shows the network operator and country again. It had been showing "--" for both on every install since the address lookup changed its response format.
- Adds a Network Log Upload setting, on during the test programme. While it is on, Tono uploads its own log — the hostnames you connected to, the process that opened each connection, and which rule and route it matched — to Tono support, so a routing fault can be diagnosed without asking you to find and send a file. Credentials, URL queries and page content are removed before anything is written to the log, and TLS bodies are never observed. Uploads are linked to your account, readable only by Tono administrators, and deleted after 14 days. Turning the setting off stops the upload and nothing from the log leaves your Mac.
- The Support page can send the newest log segment immediately, for when you are in a support conversation and waiting for the next upload would lose the fault.
- Signing in stays valid for longer stretches without a pause. Tono now renews its access before it expires instead of after, which removes a recurring interruption every fifteen minutes that was slowest on connections from China.
- If the control plane's address changes, a Mac that is fail-closed with no tunnel can still reach it. Tono now remembers the addresses it saw while connected, instead of relying only on the ones built into the app.
- The direct-path health check now tests a WeChat server on the same port as WeChat's own traffic, rather than an unrelated host, so a problem affecting that traffic is one the check can actually see.
- Corrects the Aggregated App Routing Research setting, which described itself as on by default while shipping off.
