# Tono 0.0.74

**本版备用通道仅手动。** Tono 不会自己切过去。

- 默认路径一键连接，带城市名。连上之后，仪表盘和活动应停在已连接。如果又跳回重试，把诊断块复制发过来。
- 某个城市连不上或连不稳时，可以自己选 **备用通道**。不会自动打开，也不是每个账号都能看见。
- 连接失败时主界面是一句短原因。支持页可以复制失败阶段和错误码，用来报修。
- **新安装默认开启「上传网络日志」。** 以前关掉过的，仍保持关闭。上传你连接过的主机名、发起每条连接的程序、命中的规则与路由，用来排查连接不稳和掉线。不含页面内容、密码或节点密钥。可在设置里关闭。
- 安装或更新 Tono 时，系统可能要求输入 Mac 管理员密码，用来安装或修复 Tono 网络 Helper。只批准写明 Tono 的请求。
- 需要 Apple 芯片的 Mac、macOS 26.3 或更高。没有 Intel 版，没有手机端，没有 Linux 端。
- 睡眠唤醒未认证。醒后若会话没回来，再连一次。
- 更新没能完成时，仪表盘会提示。请先断开并退出 Tono，再手动安装新版本。

## 已知限制

不承诺所有网站、所有银行 3-D Secure、所有 Secure DNS 都能过。

- [#331](https://github.com/raydocs/tono/issues/331)：连接断开、Tono 拦住流量期间，macOS 会留一个很窄的口子，让 Tono 能连回自己的服务来恢复。这个口子目前还没有只限于 Tono 本身。修复排在后续版本。
- [#17](https://github.com/raydocs/tono/issues/17)：未覆盖全部浏览器 Secure DNS、银行 3DS 和登录后支付。
- [#4](https://github.com/raydocs/tono/issues/4)、[#5](https://github.com/raydocs/tono/issues/5)：计量不在这一版里。
