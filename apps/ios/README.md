# Tono for iOS — patched mobile runtime candidate

iOS/iPadOS 26+, SwiftUI, Network Extension. G1/G2 work in Draft
[#204](https://github.com/raydocs/tono/pull/204), tracked by
[#210](https://github.com/raydocs/tono/issues/210). **Not device-qualified,
not an App Store/TestFlight release, and not proof of a system-wide kill switch.**
No macOS, Windows, Android, backend or customer-feed behavior changes.

## The previous libbox source blockers now have executable implementations

The owner authorized a distinct Apple build and minimal upstream patches.
`Configuration/core-requirement.json` preserves the desktop pins separately from
`mobile`: sing-box 1.15.0-alpha.3, upstream
`93fff5954390367dd456cad3cbd79be54f8b941f`, Go1.27.1, the four original tags plus
`tono_mobile`, Apple CGO1/c-archive, gomobile v0.1.12, arm64 device + simulator.
The shared desktop PR #202 is not relabeled as an Apple artifact.

The follow-up review fixes are source-tested against complete, freshly generated
Worker envelopes (`updatedAt` and per-account `routingSha256` included), not
hand-trimmed wire fixtures. Catalog discovery is independent of connection
selection. Node-specific transport/TLS allowlists reject unknown requirements;
only explicit display metadata (`icon`) may be ignored.

All upstream changes are auditable, hash-locked patches in `patches/`:

- **Linker:** mobile excludes the optional raw OOM-profile writer that imported
  unsupported runtime linknames. No `-checklinkname=0`, Go runtime modification,
  stock framework or hidden prebuilt code. Nonmobile behavior stays unchanged.
- **Packet flow:** libbox's small Tono session API uses a bounded gVisor channel
  endpoint. A sing-tun factory hook selects it only for a Tun implementing that
  explicit interface; existing NativeTun paths remain unchanged. No utun FD,
  KVC, descriptor scanning, socketpair pretending to be NativeTun, or deprecated
  `stack` config option. Packets contain only the IPv4/IPv6 datagram, no Darwin
  four-byte prefix. Close cancels blocked reads; input length/MTU is checked.
- **HY2 DER:** a new, actually implemented `certificate_leaf_sha256` option
  selects the Go TLS verifier. It compares SHA256 of the complete leaf DER in
  constant time, verifies hostname and validity, and runs on resumed sessions.
  It replaces CA trust for the exact provisioned leaf; it is NOT SPKI pinning.
  User `insecure`, missing SNI, alternate engines, CA/SPKI overrides and
  Reality/uTLS/ECH combinations with this option refuse. Production compilation
  enables it only for admitted HY2. Tests exercise the actual HY2 dependency's
  QUIC implementation, including a same-key/different-leaf certificate.

`Mobile/ABI/Tonomobile.objc.h` is generated by the pinned gobind, not hand-written.
Only Prepare/Locations/Watermark/Start/Read/Write/Probe/Close/Identity are bound;
the full libbox command server and platform FD API are not exposed to Swift.
Generated zero-value constructors refuse safely. `tonomobile-v1` is a source ABI,
not a claim that the Apple linker/Swift importer has executed.

## Admission, credentials and runtime lifecycle

- Complete bounded HTTPS response bytes reach the Go compiler. JSON duplicate,
  alias/unknown-key and YAML alias rejection; Worker base64url digests; production
  Ed25519 signature key/context; public IPv4 endpoints and Reality identity checks.
  HY2 must share its VLESS node's address and account credential and retain DER.
- Raw cloud YAML DNS/rules never become runtime. The emitted config uses proxy
  DoH with real IPv4 answers, empty AAAA, dual-family capture, IPv6 rejection, DNS
  interception before generic UDP rejection. There is no host DNS fallback,
  controller listener, arbitrary imported config or persistent core cache.
  No volatile FakeIP mapping can reassign cached application addresses on renewal
  or process restart. Legacy synthetic destinations in `198.18.0.0/15` refuse
  (after DNS interception); an upgrade may require application DNS-cache expiry.
- Manual selection is persisted metadata. It overrides the explicit cloud
  default; disappearance/failure never selects another city. The managed list
  is exposed after complete admission even without a cloud default. Changing
  selection pauses first; the user connects again. Automatic still requires an
  explicit cloud default; inventory visibility does not grant fallback authority.
- The app-only refresh token never enters the App Group or extension. A separate
  `$(AppIdentifierPrefix)com.ninx.tono.tunnel` Keychain group grants only the
  access token, account/device scope, generation and selected node. The extension
  cannot access `com.ninx.tono` account Keychain items. Both use
  AfterFirstUnlockThisDeviceOnly, no sync/backup. No raw catalog or policy on disk.
- The extension refetches `/me`, `/devices`, catalog and signed policy on every
  start/renewal from the fixed HTTPS origin, refusing redirects, revoked devices,
  mismatched accounts, stale local grants, unavailable storage or unsupported
  policy. Bounded streaming avoids an unbounded URLSession body in NE memory.
- Account/device watermarks persist **before** network settings/core startup.
  Rollback, same-revision changed bytes (including raw routing), corrupted
  and duplicate receipts refuse. Logout retains anti-rollback history but deletes
  the grant. A revision is not a signed expiration time.
- Renewal currently closes/recreates the core every 120 seconds after fresh
  admission. A monotonic Go five-minute hard lease closes the core if native
  renewal stalls. This intentionally interrupts existing flows; seamless reload
  is not claimed. Admission objects expire after 30 seconds.
- The provider installs IPv4/IPv6 default routes, MTU1280, DNS matchDomains `[""]`,
  then starts Go and probes TLS **through the selected outbound**, not an escaping
  URLSession. A five-second heartbeat checks local grant and proxy health.
  Protected requires current-generation route/DNS/core/probe receipts and health
  no older than ten seconds. No promotion from NEVPNStatus alone. Queue epochs
  fence old output/probe callbacks; at most one NE read is pending across reloads.
- On Demand saves/reloads the strict profile, then starts. Pause deletes the
  extension grant and disables/saves/reloads the profile before stop. A failed
  grant revoke still attempts profile disable/stop. Forget, cleanup retry and
  terminal auth loss retain durable logout intent until both credential domains
  and profile quiescence complete. An active manager is inspected before grant
  replacement; Connect reobserves its authorized generation. Missing foreground
  health withdraws Protected without terminalizing that generation; genuinely
  failed/paused generations remain fenced. Extension failure cancels the tunnel;
  OS reconnect may retry but must pass fresh admission.
  Within an app-model instance, failed, paused and superseded generations cannot
  reattach. Reobserving the current live generation preserves its receipt replay
  floor and health state; only a previously unseen authorized generation starts
  a fresh observation window. These fences are not a persisted revocation list.
  App relaunch reattaches to an authorized generation without trusting cached
  Protected state. Missing/mismatched embedded identity refuses before install.

**Still explicit contract limits:** process-scoped desktop DIRECT rules, all
home directives, unsupported TLS options and unknown future policy semantics
refuse. Current cloud routing has no ordered backup list or entry-fallback grant;
the standalone residential state-machine tests are not runtime home support.
An expired extension access token requires reopening the app for refresh; the
extension cannot refresh indefinitely with the current least-privilege grant.
The provider owns one live session at a time; concurrent libbox instances and
seamless in-process handoff are not qualified. Do not infer multi-instance safety
from the sequential renewal/restart tests.
These are genuine remaining functional limits, not Apple execution evidence and
not reasons to silently drop policy or share refresh credentials.

## Reproduce all portable checks

Use clean exact sing-box and sing-tun checkouts, Go1.27.1 and Node24.18.0. Install
Worker test dependencies with `npm --prefix services/control-plane ci` from its
lockfile before either the portable or Apple build. Populate the
checksum-locked module cache with `go mod download` in sing-box first. The Orb's
verified Linux Go archive SHA256 was
`63d339f0da5ab53635a56f2490a7984dfe12dfcff22ad749f63edaf590168445`.

```sh
python3 apps/ios/tools/build-mobile.py \
  --source /path/to/pinned-sing-box --tun-source /path/to/pinned-sing-tun \
  --go /path/to/go1.27.1/bin/go --out /new/path/mobile-evidence
python3 apps/ios/tools/project.py --check
python3 apps/ios/tools/test_static.py
node apps/ios/tools/check-cloud-contract.mjs
git diff --check
```

The builder archives clean refs, checks module/patch hashes, applies patches only
to a disposable stage, runs real parser, packet-flow, QUIC and receipt/expiry
tests, generates/compares Objective-C ABI, links and executes a libbox-dependent
binary and compares repeat-build hashes. Dependencies cannot download or float.
Unified-diff context whitespace is preserved verbatim in the upstream patches;
path-scoped Git attributes distinguish it from source whitespace, while the
builder checks actual source additions with `git apply --whitespace=error-all`.
The real Worker producers encrypt/decrypt disposable rows and serialize complete
envelopes into the Go test stage. A packet-level regression uses local TLS DoH
through a SOCKS witness and verifies cached TCP destinations across recreation
and a fresh subprocess, including rejection of legacy synthetic addresses.
It writes source/toolchain/ABI/output identity and license/module receipts.
`check-runtime.py` forwards to these stronger checks; `--tun-source` is now required
and linking is mandatory. No test is replaced with a stock archive-only success.

`verify-mobile.py --directory <output> --receipt-sha256 <independently-reviewed-digest>`
checks source inputs, patches, ABI and artifact bytes. Add `--require-apple` before
Xcode; Linux artifacts must fail that gate. The receipt must come from a trusted
review/build channel. A self-declared manifest is not provenance or signing.

Linux tests do **not** execute Swift, Apple SDK compilation/linking, NE routing,
Keychain entitlements, On Demand, native UI/VoiceOver, or device memory/energy.
No native screenshot is available; preview art is not a rendered-app check.
The XCTest/UI tests include failed shared-grant revoke/retry, active Connect and
foreground reattachment and remain unexecuted here. The separate CI workflow failed
upload for missing GitHub `workflows` permission; use the latest preserved patch,
not the old archive-only recipe. Existing Services CI is not iOS evidence.

## Minimal Mac Studio and iPhone acceptance runbook

Use the exact PR SHA reported in the handoff, not an unrecorded later branch head.
Do not use a MacBook build fallback or change provisioning identifiers.

1. On Mac Studio (or disposable hosted `macos-26` for unsigned checks), record
   `xcodebuild -version`, `xcrun --sdk iphoneos --show-sdk-build-version` and the
   corresponding `iphonesimulator` value. Require Xcode/iOS26+, Go1.27.1 and the
   exact two upstream commits. Populate their locked module cache, then:

   ```sh
   python3 apps/ios/tools/build-mobile.py \
     --source "$BOX" --tun-source "$TUN" --go "$GO" --out "$EVIDENCE/mobile" \
     --apple --xcode-build '<reviewed-build>' --sdk-build '<reviewed-device-sdk-build>' \
     --simulator-sdk-build '<reviewed-simulator-sdk-build>'
   # Independently record/review receipt.json SHA256; never relabel Linux output.
   python3 apps/ios/tools/verify-mobile.py --directory "$EVIDENCE/mobile" \
     --receipt-sha256 '<reviewed-receipt-sha256>' --require-apple
   xcodebuild -project apps/ios/Tono.xcodeproj -scheme Tono \
     -xcconfig "$EVIDENCE/mobile/mobile.xcconfig" -configuration Debug \
     -destination "platform=iOS Simulator,id=$SIMULATOR_ID" \
     -derivedDataPath "$EVIDENCE/DerivedData" -resultBundlePath "$EVIDENCE/Tests.xcresult" \
     CODE_SIGNING_ALLOWED=NO test
   xcodebuild -project apps/ios/Tono.xcodeproj -scheme Tono \
     -xcconfig "$EVIDENCE/mobile/mobile.xcconfig" -configuration Release \
     -destination 'generic/platform=iOS' -derivedDataPath "$EVIDENCE/Release" \
     CODE_SIGNING_ALLOWED=NO build
   ```

   The generated xcconfig selects the correct static framework slice, linker
   flags and matching compiled/bundle identity. No runtime framework download or
   Xcode shell build phase. Run missing-core unit tests without the xcconfig too;
   those tests intentionally expect unavailable admission. Retain nonzero test
   counts and exact errors. An unsigned device build is not an installed tunnel.
2. Inspect signed entitlements for both IDs and the narrow Keychain groups;
   register/approve them with the owner's Apple team. Do not auto-provision or
   upload. Run on a dedicated iOS26+ device with an authorized test account and
   an explicitly compatible signed policy/catalog. Check Reality and HY2 TCP,
   DNS, IPv6 rejection, wrong DER/same-key leaf rejection and no direct fallback.
3. Capture traffic on Wi-Fi and cellular, including network handover, lock/first
   unlock, sleep/reboot, app kill, extension crash/jetsam and low-memory stress.
   Confirm provider sockets escape correctly without captured recursion, MTU
   behavior and no stale Protected during failed probes, renewal or revocation.
   Verify pause across reboot and absent grant, manual-pin disappearance, rollback,
   corrupted Keychain receipts, API offline/401 and token expiry. Home/DIRECT
   policies must refuse until their separate contract/adapter gate is resolved.
4. Review actual native light/dark/Dynamic Type/VoiceOver states, managed location
   selection, diagnostics minimization, and privacy/license/export requirements.
   Resolve GPL corresponding-source and Apple distribution obligations before

## Apple coverage and diagnostics remain deliberately bounded

`includeAllNetworks=true`, all optional local/APNs/cellular exclusions false,
`disconnectOnSleep=false`. `enforceRoutes=false` because Apple applies it only
when includeAllNetworks is false. Apple still excludes DHCP/control traffic,
captivity and some cellular/companion services; test and document those exceptions.
Failure to start is admission refusal, not proof that traffic outside a stopped
extension is blocked. See Apple's documentation for
[includeAllNetworks](https://developer.apple.com/documentation/networkextension/nevpnprotocol/includeallnetworks).

Typed in-memory diagnostics contain only fixed events/error codes and coarse
times, never packet bytes, domains, tokens, UUIDs, raw errors, account/node names
or catalog/policy content. Default TestFlight Comprehensive is allowlisted, not
raw logging; production/unknown distribution caps at Minimal; Off clears/disables.
The existing Worker telemetry validator/digest fixtures are exercised locally.
Ops flatten/status currently does not map these events to connection history;
do not claim ops compatibility. No background diagnostics uploader is enabled.
App account cleanup keeps the existing durable logout intent and retry UI;
unresolved simultaneous marker/Keychain failure remains visible, not a promise
that process memory can guarantee durable logout.
