# Tono 0.0.84 — 客户手动测试 RC

这是替代 0.0.83 RC 的手动安装测试候选，不是 Windows 稳定验收或自动更新推广。支持 x64 Windows 10 22H2 / Windows 11。

0.0.83 之后新增：

- **修复：在会按 TLS 名称重置 `api.afk.ccwu.cc` 的网络里仍然登不上**（#1838、#1839）。现在经中继访问控制面时，Tono 改用 `static.bicon.dev` 这个名称（登录前的网络自检也一样），它指向同一套 API，两台中继都放行。只有中继这条路径换名；隧道已运行、固定地址和更新下载仍用原来的域名。防火墙规则集不变。
- 0.0.83 的内容全部保留。

## 安装与必须测试的项目

先核验发布的 SHA-256。旧 Tono 选择「恢复」，确认普通上网正常，连托盘一起退出，再以管理员身份在固定的 Program Files 位置运行安装程序；本次测试不要用受保护的应用内更新。0.0.32–0.0.34 不能直接覆盖：确认恢复后正常卸载、重启再安装本候选。恢复、卸载或已装校验失败就停止并联系支持。

在 0.0.83 提示连不上中继的网络里，先不连接 Tono，退出登录再登录，确认能登录；连接后确认防火墙仍然挡住绕过隧道的流量。然后重做 0.0.83 的测试项。记录系统、旧版本与候选哈希。

## 已知限制

- 没有隧道时登录仍只走这两个中继。如果某个网络把 `static.bicon.dev` 也封了，就需要再换名称；旧版安装仍用旧名称，所以这样的客户首次登录要手动安装本版，或换一个网络。
- 检查更新和下载仍使用 `releases.afk.ccwu.cc`。
- 0.0.83 的限制仍然有效：流水线用的是 Tauri 更新签名，不是 Authenticode 发布者证书，可能出现 SmartScreen 提示；防泄漏规则、G1–G3、真实 WFP/DNS 故障行为和升级/回退未验收。
