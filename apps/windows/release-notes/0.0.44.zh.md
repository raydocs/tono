# Tono 0.0.44

这版修复了连接和切换节点时的竞态，避免界面所选节点、实际隧道和 Windows 断网保护互相对不上。

- 同一时间只允许一次节点切换修改选择器和 Windows 筛选平台（WFP）。连续快速选择两个节点时，两个切换任务不会再互相回滚；第一次完成前，第二次会提示稍后重试。
- 如果确认 WFP 断网保护或受保护 DNS 失效，会强制进入受保护的修复流程。即使 HTTPS 暂时能通，也不能再掩盖断网保护边界本身已经损坏。
- 网络原地恢复后，连接监控和控制面地址刷新仍会继续运行。节点后来失效时能够被发现，不会整段会话一直错误显示「已连接」。
- 自动重连现在有明确的次数上限。确定性故障不会再每三十秒无限重试，也不会反复请求管理员授权。
- 切换节点或点击「立即重试」会重新启用已经耗尽的重连预算；错误信息改成用户能看懂的诊断，不再显示内部探测标记。
- 即使自动重连已经停止，服务修复仍然可用，不会让电脑停在「保护仍开着但没有恢复办法」的状态。

安装包带有 Tono 自动更新签名，但没有 Authenticode 发布者证书，全新安装时 Windows SmartScreen 仍可能告警。
