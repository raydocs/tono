# Tono 0.0.86

Supports x64 Windows 10 22H2 / Windows 11.

## Changes since 0.0.85

- **Signed TCP direct IPs** (#1856): The signed `traffic-policy` can now carry `tcpDirectAddresses` (non-DNS IPv4 TCP destinations) and v5 `tcpEndpoints`. The Windows service admits and routes them direct, so a policy update can add or change them without a client rebuild.
