# Tono 0.0.82 — 客户手动测试 RC

这是替代 0.0.80 RC 的手动安装测试候选，不是 Windows 稳定验收或自动更新推广。0.0.81 构建过但没有发出，它的内容也一并列在这里。支持 x64 Windows 10 22H2 / Windows 11。

0.0.81 之后新增：

- **修复：稳定模式和三层分流下，部分流量可能绕过隧道**（#1820）。桌面分流现在带上和移动端相同的防泄漏规则：DNS-over-TLS（853 端口）、STUN（含 IPv6）、海外 UDP、DNS HTTPS/SVCB 查询、家宽辅助域名和 X 的域名（`grok.x.com` 仍走家宽）。
- **修复：放行后重连可能把你换到另一台节点**（#1793）。选中 `X · hy2` 时，Tono 先验证 X 自己的 TCP 块，再试同区其他节点，与 macOS 一致。
- **修复：切换节点时遇到唤醒，会白白用掉一次隧道重建名额**（#1785）。交给进行中切换的那次重建不再计入每小时三次的上限，也不再把线路标为不稳；切换结束后检查仍失败就立即重建。
- **修复：未受邀的邮箱登录时也显示「请查收邮件」**（#1778、#1796）。验证码步骤现在说「如果这个邮箱已开通 Tono，验证码会在一分钟内送达」，一分钟后说明 Tono 目前只对受邀用户开放。Tono 的邮件服务异常时，验证码步骤会直说。
- **修复：套餐到期被说成「登录已失效」**（#1778、#1796）。登录页和会话页现在按服务器这次的拒绝码说明：套餐已到期、本期流量已用完，或账号还没有开通套餐。续费后点「已续费，重新登录」即可。
- **新的登录页布局**（#1791、#1777）。常规窗口尺寸下，海面场景在左、登录表单在右。欢迎页加了进度条、「n / 3」和「上一步」；验证码步骤把收件邮箱放在验证码格上方。动效遵守减少动态效果设置。
- **安装包更小**（#1798）。内置 emoji 字体只保留旗帜（1.45 MB → 0.1 MB），其余 emoji 用系统 Segoe UI Emoji。
- 依赖更新：rustls 0.23.46（#1794）和前端依赖组（#1763）。

同时包含 0.0.81 的内容（#1759、#1766）：

- 连接失败后写明下一步：节点没应答时提供换节点；普通网络失败提示重试；隧道检查没过或别的 VPN 占住网络时会点名；无法归类的失败显示支持码。
- Wi-Fi 或网卡反复抖动时，一小时最多重建三次隧道，之后保持隧道并显示「这条线路最近多次中断」。
- 受保护隧道的健康检查问两个互不相关的站点，两个都失败才算失败。
- 连接被更新或「恢复正常网络」取代时，说明这次已作废，而不是报网络错误。
- Chrome 或 Edge 的安全 DNS 检查慢时会再试一次，仍不行就提示先关掉 Chrome 和 Edge。
- 隧道锁定后连接失败，最多提前 8 秒给出结果。
- 0.0.80 的内容全部保留：恢复没做完时连接会自己先恢复一次；AI 名单 194 条；海景动画后台停帧；默认仍是稳定模式，普通 DIRECT 仍仅支持公网 IPv4 TCP80/443。

## 安装与必须测试的项目

先核验发布的 SHA-256。旧 Tono 选择「恢复正常网络」，确认普通上网正常，再连托盘一起退出。以管理员身份在固定的 Program Files 位置正常运行安装程序；本次测试不要用受保护的应用内更新。**0.0.32–0.0.34 不能直接覆盖：**确认恢复后，正常卸载、重启再安装本候选，有保留应用数据选项时保留。恢复/卸载或已装校验失败就停止并联系支持，不要绕过门槛或手删受保护资源。

先测稳定模式，再显式打开三层分流：连接/活动、实际 DNS 与云端/家宽/直连出口、换云端时家宽身份、受保护路径故障、Core/Service 死亡、重启、显式恢复、双向省流自动恢复、睡眠/唤醒与 Wi-Fi 切换。本候选另加：稳定和三层下，用 WebRTC/STUN 泄漏测试和 DoT（853）查询确认看不到本机 IP 或本地解析器，`grok.x.com` 仍从家宽出口；选中 `X · hy2` 节点后「恢复正常网络」再重连，确认仍是 X；切换节点过程中让电脑睡眠，唤醒后能重连；用未受邀邮箱和已到期账号登录，核对提示。0.0.81 的测试项照做：挂掉的节点会提供换节点；反复开关 Wi-Fi，第三次重建后不再重建并出现线路提示；慢盘上开着 Chrome 连接能完成或点名 Chrome 和 Edge。记录系统、旧版本与候选哈希。跨版本手动覆盖和受保护自动升级仍未验收。

## 已知限制

- 流水线用的是 Tauri 更新签名，不是 Authenticode 发布者证书，可能出现 SmartScreen/未知发布者提示；不要为运行候选关闭安全策略。实际包签名结果以交付回执为准。
- 隧道锁定后控制器、隧道、代理三项检查全失败时，Tono 仍分不清是节点死了还是本机隧道坏了，这条提示保留通用说法和支持码。
- 防泄漏规则（#1820）在代码上与移动端合同一致，尚未在 Windows 真机上实测；四台线上出口的 Reality/TCP 配置只在仓库里钉住，没有重新测量。
- 登录仍没有开放注册、Apple 登录和续费按钮；无套餐提示请你联系邀请你的人。
- #1071/#1504 仍独立；HOLD #1643 多用户接管与 #1733 不包含。#1605 DHCP 回退已包含但未在真机验证；DNS 恢复失败仍可能需要支持协助。
- G1–G3、真实 WFP/DNS 故障行为、升级/回退与固定候选试用尚未验收。不要为回退在本候选上覆盖安装旧版本，请联系支持。
- 保留已有日志偏好；新安装默认上传网络日志，可在设置调整。
