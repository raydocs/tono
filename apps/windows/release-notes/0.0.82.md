# Tono 0.0.82 — customer-test RC

Manual-install test candidate that replaces the 0.0.80 RC, not stable Windows qualification or automatic-update promotion. 0.0.81 was built but never handed out, so everything in it is listed here too. Requires x64 Windows 10 22H2 or Windows 11.

New since 0.0.81:

- **Fixed: Stable and Three-tier could let some traffic around the tunnel** (#1820). Desktop routing now carries the same anti-leak rules as the mobile apps: DNS-over-TLS (port 853), STUN including IPv6, overseas UDP, DNS HTTPS/SVCB lookups, the Home helper domains and X's domains (`grok.x.com` still goes through Home).
- **Fixed: reconnecting while protection is released could move you to another server** (#1793). With an `X · hy2` server selected, Tono now proves X's own TCP block first, then the rest of the same region, as on macOS.
- **Fixed: a wake-up during a server switch used up a tunnel rebuild** (#1785). A rebuild handed to a running switch no longer counts against the three-per-hour limit or marks the route unstable; if the check still fails after the switch, the tunnel is rebuilt straight away.
- **Fixed: sign-in said "check your mail" for an email that was not invited** (#1778, #1796). The code step now says the code arrives within a minute if the address has Tono, and after a minute explains that Tono is invite-only. When Tono's mail service is having trouble, the code step says so.
- **Fixed: an expired plan was shown as "sign-in expired"** (#1778, #1796). Sign-in and the session screen now say the plan has expired, this period's data is used up, or the account has no plan yet, taking only the server's refusal code. After renewing, "Renewed, sign in again" signs you back in.
- **New sign-in layout** (#1791, #1777). On normal window sizes the sea scene sits beside the sign-in form. The welcome screens have a progress bar, "n / 3" and a Back button; the code step shows which email the code went to above the code boxes. Motion respects reduced-motion.
- **Smaller app** (#1798). The bundled emoji font now carries only flags (1.45 MB → 0.1 MB); other emoji use Segoe UI Emoji.
- Dependency updates: rustls 0.23.46 (#1794) and the frontend group (#1763).

Also in this build, from 0.0.81 (#1759, #1766):

- A failed connection says what to do next: a server that did not answer offers another server; a plain network failure says to retry; a tunnel check or another VPN is named; anything unclassified shows its support code.
- A flapping Wi-Fi or adapter rebuilds the tunnel at most three times an hour, then keeps it up and shows the "this route dropped several times" hint.
- The protected-tunnel health check asks two independent sites and fails only when both fail.
- A Connect superseded by an update or Restore internet says it was cancelled instead of reporting a network failure.
- A slow Chrome or Edge Secure DNS check retries once, then asks you to close Chrome and Edge.
- A failed connect after the tunnel is locked reports up to 8 seconds sooner.
- Everything in 0.0.80 is retained: Connect runs Restore internet once by itself after an unfinished restore; the AI list has 194 entries; the sea animation idles in the background; Stable remains the default and ordinary DIRECT stays public IPv4 TCP80/443 only.

## Installation and required tests

Verify the published SHA-256. Restore Normal Internet in the old Tono, confirm ordinary internet, then quit including the tray. Run the installer normally as administrator at the fixed Program Files location; do not use protected in-app update for this test. **0.0.32–0.0.34 must not be directly overwritten:** after verified restoration, normally uninstall, restart and install this candidate, retaining application data where offered. Stop and contact support if restore/uninstall or existing-installation validation fails; never bypass the gate or delete protected resources manually.

Test Stable first, then explicitly enable Three-tier: connection/Activity, actual DNS and cloud/Home/DIRECT egress, Home identity while changing cloud, protected-path failure, Core/Service death, restart, explicit restore, save-mode-then-auto-recovery in both directions, sleep/wake and Wi-Fi changes. Also for this candidate: in Stable and Three-tier, confirm a WebRTC/STUN leak test and a DoT (853) lookup do not show your local IP or resolver, and that `grok.x.com` still exits through Home; select an `X · hy2` server, Restore internet, then reconnect and confirm X is kept; sleep the PC during a server switch and confirm it reconnects after wake; sign in with an uninvited email and with an expired account and confirm the messages. Carry over the 0.0.81 items: a down server offers another server; repeated Wi-Fi toggles stop rebuilding after the third and show the route hint; Connect with a slow Chrome finishes or names Chrome and Edge. Record OS, old version and candidate hash. Other-version manual overwrite and protected automatic upgrades remain unqualified.

## Known limits

- The pipeline uses the Tauri updater signature, not an Authenticode publisher certificate. SmartScreen/unknown-publisher warnings may appear; do not disable security policies to run the candidate. Check the delivery receipt for actual package signing results.
- When the controller, tunnel and proxy checks all fail after the tunnel is locked, Tono still cannot tell a dead server from a broken local tunnel; that message keeps its generic code and the support code.
- The anti-leak rules (#1820) match the mobile contract in code; they have not been measured on a real Windows device. The four live exits' Reality/TCP settings are only pinned in the repository, not re-measured.
- Sign-in still has no open sign-up, Apple sign-in or renewal button; the no-plan message asks you to contact whoever invited you.
- #1071/#1504 remain independent; HOLD #1643 multi-user takeover and #1733 are not included. The #1605 DHCP fallback is included but unverified on hardware; DNS restoration failure may still require support-assisted recovery.
- G1–G3, real WFP/DNS fault behavior, upgrade/rollback and a fixed-candidate trial remain unverified. Do not install an older version over this candidate for rollback; contact support.
- Existing logging preferences remain; fresh installs upload network logs by default, configurable in Settings.
