# Tono 0.0.33

**Install this one by hand.** Tono cannot update itself to this version. The key that
proves an update genuinely came from us has been replaced, and a copy of Tono already on
your PC only trusts the previous one. Once 0.0.33 is installed, automatic updates work
again and keep working.

- Tono asks a reachable address whether an update exists. Every earlier build asked
  `raw.githubusercontent.com`, which is blocked from mainland China — so the update check
  could only succeed while Tono was already connected, and a PC that could not connect was
  told there was nothing to install. That is the moment an update matters most. The check
  now goes to Tono's own server, the same one the Mac has always used.
- The update signing key has been replaced and is no longer held in a single place that
  could be lost. This is why this version must be installed by hand: an installed copy
  checks the signature against the key it was built with, and correctly refuses one it does
  not recognise.

Everything else is unchanged from 0.0.32, including the Service protocol, so the App and
the Service still pair exactly as before.
