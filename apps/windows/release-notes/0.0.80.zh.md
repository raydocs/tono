# Tono 0.0.80 — 客户手动测试 RC

这是手动安装测试候选，不是 Windows 稳定验收或自动更新推广。旧 0.0.79 RC 保留不变。支持 x64 Windows 10 22H2 / Windows 11。

- **修复：「恢复正常网络」没做完时，连接一直被挡回**（#1705）。重启后每次点连接都提示「上次恢复没完成」，要求再点恢复。现在连接会自己先恢复一次再连，每次点击最多一次；需要重启 Windows 的情况会直接说明，不反复重试。
- **更多 AI 服务走家宽**（#1706）。AI 名单增加到 194 条：Amp、Cursor、GitHub Copilot、Kiro 与 Amazon Q、Windsurf/Codeium、JetBrains AI、Hark、Mistral、ElevenLabs、Midjourney、Suno、Google Labs/Flow/Opal/Stitch、Llama，以及之前漏掉的 Poe、Perplexity、OpenAI 相关域名。有家宽线路时，它们和其他 AI 服务一样走家宽。
- **修复：海景动画在后台持续占用 GPU**（#1707）。窗口在其他应用后面、最小化或收进托盘时，画面停在当前一帧，回到前台接着动；登录页和引导页不再多渲染一层看不见的海景。前台动效不变。
- 0.0.79 的内容全部保留：默认仍是稳定模式；可选三层分流须显式断开再连接才生效；普通 DIRECT 仍仅支持公网 IPv4 TCP80/443；移动云和工信部备案网站直连。

## 安装与必须测试的项目

核验发布的 SHA-256。旧版先“恢复正常网络”，确认普通上网，再退出含托盘进程；正常以管理员运行安装器，保留固定 Program Files 路径，不使用受保护的应用内更新。**0.0.32–0.0.34 不可直接覆盖：**确认网络恢复后正常卸载、重启再装，可选时保留应用数据。恢复/卸载或旧安装校验失败就停止联系支持，不绕过门禁、不手删受保护资源。

先测稳定模式，再显式开启三层：连接/Activity、真实 DNS 及云/Home/直连出口、换云保持 Home 身份、保护路径失败、Core/Service 死亡、重启、显式恢复、两个方向保存模式后自动恢复、睡眠/唤醒和换 Wi-Fi。另外：重启后恢复没做完时，点一次连接就能恢复并连上；Tono 在其他窗口后面时，任务管理器里 GPU 接近空闲。记录系统、旧版本、候选摘要；其它旧版覆盖及受保护自动升级仍需实测。

## 已知限制

- 现有流程提供 Tauri updater 签名，不是 Authenticode 发布者证书；可能显示 SmartScreen/未知发布者。不能关闭系统安全策略来测试；实际验签结果以交付回执为准。
- #1071/#1504 独立保留，HOLD #1643 多用户接管未包含。#1605 DHCP 兜底已包含但未经实机验证；DNS 恢复失败仍可能需要支持协助。
- G1–G3、真实 WFP/DNS 故障、升级回退和固定候选试用未验收；不要覆盖安装旧版回退，请联系支持。
- 保留已有日志偏好；新安装默认上传网络日志，可在设置修改。
