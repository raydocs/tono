# Tono 0.0.83 — 客户手动测试 RC

这是替代 0.0.82 RC 的手动安装测试候选，不是 Windows 稳定验收或自动更新推广。支持 x64 Windows 10 22H2 / Windows 11。

0.0.82 之后新增：

- **修复：登录时提示「连不上任何一台中继」**（#1836）。中继列表改为两个地址：Westwood 的新 IP 和 Mesa，去掉被封的旧 Westwood 地址和 Arosscloud 中继。没有隧道时 Tono 只通过中继访问控制面。中继的防火墙规则集换了新版本号，服务启动时会替换旧规则。
- 0.0.82 的内容全部保留。

## 安装与必须测试的项目

先核验发布的 SHA-256。旧 Tono 选择「恢复」，确认普通上网正常，连托盘一起退出，再以管理员身份在固定的 Program Files 位置运行安装程序；本次测试不要用受保护的应用内更新。0.0.32–0.0.34 不能直接覆盖：确认恢复后正常卸载、重启再安装本候选。恢复、卸载或已装校验失败就停止并联系支持。

在旧版提示连不上中继的网络里，先不连接 Tono，退出登录再登录，确认能登录；连接后确认防火墙仍然挡住绕过隧道的流量。然后重做 0.0.82 的测试项。记录系统、旧版本与候选哈希。

## 已知限制

- 没有隧道时登录只走这两个中继；两个都连不上的网络仍然登不上。旧版安装会一直带着被封的地址，所以这样的客户首次登录要手动安装本版，或换一个网络。
- 0.0.82 的限制仍然有效：流水线用的是 Tauri 更新签名，不是 Authenticode 发布者证书，可能出现 SmartScreen 提示；防泄漏规则未在 Windows 真机实测；G1–G3、真实 WFP/DNS 故障行为和升级/回退未验收。
