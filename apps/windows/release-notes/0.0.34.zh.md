# 0.0.34
> 可从 0.0.33 自动更新。本版以打磨与中文质量为主。

- 切换节点后会弹出轻提示，标明已切换到哪个节点，不再无声切换
- 全面梳理中文文案：统一称"节点"，中文语境使用全角标点，重写了若干生硬的翻译
- 节点徽章图形重制为与 macOS 逐像素一致的品牌标识
- 选中节点的高亮与卡片描边的一致性小修

## 时间线
以打磨与中文质量为主的版本：切换节点有轻提示确认、全面梳理简体中文文案（统一"节点"术语与全角标点）、节点徽章与 macOS 品牌标识逐像素对齐。服务协议不变，可从 0.0.33 自动更新。

## 限制
- 安装包未附 Authenticode 证书，全新安装时 Windows SmartScreen 会告警
- App 与 Service 必须同版；从 0.0.33 自动更新会在一次提权事务里同时替换两者
