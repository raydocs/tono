# Tono 0.0.45

This release hardens the residential routing boundary for Claude and AI assistants and resolves connection recovery race conditions on Windows.

- **Claude / AI Assistant Residential Routing Integrity**:
  - Cloudflare Turnstile human verification (`challenges.cloudflare.com`, `cf-assets.www.cloudflare.com`) is now routed through the residential hop, eliminating the fingerprint disconnect where the main site egresses via residential while challenges egress via datacenter.
  - Claude client telemetry (`browser-intake-datadoghq.com`), Statsig feature gating (`statsigapi.net`, `featuregates.org`), and Stripe Radar fraud telemetry (`stripe.network`) are routed through the residential path, keeping datacenter IPs out of Claude's security telemetry and mitigating account flagging.
- **Connection & Node Switching Hardening**:
  - Serialized node switching to prevent concurrent WFP and proxy-selector modifications.
  - Preserved health monitor and pin refresh loops across network recovery, preventing false "Connected" statuses after node failures.
  - Implemented explicit reconnection budgets to eliminate indefinite retry loops and repeated UAC elevation prompts.
  - Restored reconnect budget immediately when switching nodes or clicking retry, with human-readable diagnostic messages.

The installer carries Tono's auto-update signature, but lacks an Authenticode publisher certificate; Windows SmartScreen may present a warning during fresh installations.
