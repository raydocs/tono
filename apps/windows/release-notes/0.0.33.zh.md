# 0.0.33 · Stable
> x64、NSIS 安装包。**这一版需要手动安装**——Tono 无法自行更新到它。证明更新确实来自我们的那把密钥已经更换，而你电脑上已装的 Tono 只信任旧的那把。装上 0.0.33 之后，自动更新恢复正常并持续可用。

- Tono 现在向一个能访问到的地址查询更新。此前每一个版本问的都是 `raw.githubusercontent.com`，而它在中国大陆是被屏蔽的——所以更新检查只有在 Tono 已经连上的时候才可能成功，一台连不上的电脑会被告知没有更新可装。而那恰恰是最需要更新的时刻。现在查询走 Tono 自己的服务器，和 Mac 一直用的是同一个
- 更新签名密钥已更换，并且不再只存放在一个可能丢失的地方。这也是本版必须手动安装的原因：已安装的程序会用它构建时的那把公钥校验签名，认不出来就会拒绝——这是正确行为
- 其余与 0.0.32 完全一致，包括服务协议，所以 App 与 Service 的配对关系不变

## 时间线
把更新查询从被屏蔽的 `raw.githubusercontent.com` 挪到 Tono 自己的服务器。此前的更新检查只有在隧道已经工作时才能成功，也就是说最需要修复的用户恰恰是被告知“没有更新”的那批。同时更换了更新签名密钥并留了备份——旧密钥只存在于一处只写的 GitHub secret 中，仓库一删就永久消失。因为密钥更换，本版必须手动安装一次。

## 限制
- 已安装的旧版本无法自动更新到本版，必须手动安装一次；此后自动更新恢复
- 安装包未附 Authenticode 证书，全新安装时 Windows SmartScreen 会告警
- App 与 Service 必须同版：本版要求服务协议 14，安装器在一次提权事务里同时替换两者
