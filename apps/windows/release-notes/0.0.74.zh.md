# Tono 0.0.74

**本版备用通道仅手动。** Tono 不会自己切过去。

- 默认路径一键连接，带城市名。连上之后，仪表盘和活动应停在已连接。如果又跳回重试，把诊断块（失败阶段 / 错误码）复制发过来。
- 某个城市连不上或连不稳时，可以自己选 **备用通道**。不会自动打开，也不是每个账号都能看见。
- 连接失败时主界面是一句短原因。支持页可以复制失败阶段和错误码，用来报修。
- **新安装默认开启「上传完整流量日志」。** 以前关掉过的，仍保持关闭。上传你连接过的主机名、发起每条连接的程序、命中的规则与路由，以及断开时的上下行字节，用来排查连接不稳和掉线。不含页面内容、密码或节点密钥。可在设置里关闭。
- 安装包为 x64，支持 Windows 10 22H2 与 Windows 11。没有手机端，没有 Linux 端。
- 连接期间会暂时关掉 Windows「加密 DNS」，解析走隧道。Chrome / Edge「安全 DNS」若设成仅加密、不回退，网页仍可能打不开，请关掉或改成自动。
- 首次启动仍可能被 SmartScreen 拦住。安装包还没有 Authenticode 发布者签名，这是预期。
- 睡眠唤醒未认证。醒后若会话没回来，再连一次。
- 更新没能完成时，仪表盘会提示。请先在 Tono 里断开并退出，再手动安装新版本。

## 已知限制

不承诺所有网站、所有银行 3-D Secure、所有 Secure DNS 都能过。

- [#352](https://github.com/raydocs/tono/pull/352)：Tono 后台服务接受同一 Windows 账户下运行的程序发来的请求，而不只限于 Tono 本身。请只安装你信任的软件。把服务绑定到 Tono 本身排在后续版本。
- [#4](https://github.com/raydocs/tono/issues/4)、[#5](https://github.com/raydocs/tono/issues/5)：计量不在这一版里。
