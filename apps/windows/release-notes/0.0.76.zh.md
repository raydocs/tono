# Tono 0.0.76 — 客户测试候选

这是全新制作、手动安装的测试候选，不是已通过 Windows 真机验收的稳定版。正式自动更新源保持不动。

- 包含已合入主线的独立「恢复正常网络」组件、Wi-Fi 释放重试、Service/更新修复、DIRECT 签名策略绑定和当前固定版本的 Core/工具链；不包含 HOLD 或设计尚未放行的分支。
- 支持 x64 Windows 10 22H2 和 Windows 11，没有手机或 Linux 安装包。
- 先下载并核对公布的 SHA-256。在旧 Tono 中点 **恢复正常网络**，确认普通互联网可用，再退出（包括托盘）。以正常管理员授权运行安装器，保留固定的 Program Files 安装位置。本轮不在保护中点击 App 自动更新。
- **Windows 0.0.32–0.0.34 不可直接覆盖升级：**旧版核心文件名不符合当前替换门禁。确认网络恢复后正常卸载、重启，确认不装 Tono 也能上网，再装本候选；卸载器提供保留应用数据选项时可保留。卸载失败或提示现有安装无效时停止并联系支持，不删除受保护资源、不绕过安装门禁。
- 其它旧版可按手动覆盖路径参与测试，但具体旧版本/连接状态仍待验收。请记录旧版本和安装器结果；托管环境的未配置安装/修复测试不等于客户连接中升级。
- 请测试连接与活动、DNS/NRPT 恢复、热点切 Wi-Fi、恢复后两分钟不复锁、立即重连、重启与睡眠唤醒。

## 已知限制

- 更新安装包使用现有 Tauri 签名；现有发布流程没有 Authenticode 发布者证书，Windows 可能提示未知发布者/SmartScreen。不要为测试关闭系统安全策略。
- 不含 Draft [#1605](https://github.com/raydocs/tono/pull/1605) 的 DHCP 回退和 HOLD [#1643](https://github.com/raydocs/tono/pull/1643) 的多用户接管。DNS 恢复失败时仍可能需要支持人员协助。
- 真机 fail-closed、旧版本升级与睡眠唤醒仍待验证。保留原有日志偏好；新安装默认上传流量日志，可在设置关闭。
- 不要用旧版本覆盖本候选来回退，请联系支持人员选择兼容恢复路径。
