# Tono 0.0.36

Test candidate for China networks. GitHub prerelease only.

- Leftover names such as `US-VLESS-Reality` are moved onto a signed city
  server before connect.
- If the selected city cannot complete protected verification, Tono tries
  the next unused catalog city instead of retrying the same one.
- When Windows Encrypted DNS still returns a public address, the error
  tells you to turn Encrypted DNS off.

Before connecting on a test machine, keep Restore Network /
`tono-service.exe --emergency-disarm` ready. Kill Switch stays fail-closed.
