# Tono 0.0.74

**The backup channel is manual in this version.** Tono does not switch to it on its own.

- Connect on the default path with a named city. After you are connected, the dashboard and Activity should stay on Connected. If they bounce back to retry, copy the diagnostic block (Failed stage / Error code) and send it.
- If a city will not stay up, you can pick **Backup channel** yourself. It is not turned on automatically, and it is not in every account.
- When a connection fails, the main screen shows a short reason. Support can copy the failed stage and error code for a report.
- **Uploading the full traffic log is on by default for new installations.** If you turned it off before, it stays off. It sends the hostnames you connected to, the program that opened each connection, the matched rule and route, and bytes at disconnect, to help us fix unstable connections and drops. It never sends page content, passwords or node secrets. Turn it off in Settings.
- The installer is x64, for Windows 10 22H2 and Windows 11. No phone app. No Linux app.
- While connected, Tono turns Windows Encrypted DNS off for the session and points lookups at the tunnel. Chrome / Edge Secure DNS set to “secure only” can still block pages; set it to off or automatic.
- SmartScreen may warn on first launch. The installer is not Authenticode-signed yet. That is expected.
- Sleep and wake are not certified in this version. If the session does not come back after wake, connect again.
- If an update cannot finish, the dashboard says so. Disconnect in Tono, quit, then install the new version by hand.

## Known limits

This version does not promise every website, every bank 3-D Secure page, or every Secure DNS setup.

- [#352](https://github.com/raydocs/tono/pull/352): the Tono background service accepts requests from programs running under your Windows account, not only from the Tono app. Install only software you trust. Binding the service to the Tono app is planned for a later version.
- [#4](https://github.com/raydocs/tono/issues/4), [#5](https://github.com/raydocs/tono/issues/5): metering is not part of this version.
