# Tono 0.0.85

Supports x64 Windows 10 22H2 / Windows 11.

## Changes since 0.0.84

- **Cloud hot-push for signed `directSuffixes`** (#1851): Windows `sing-box` runtimes now admit well-formed, non-protected `directSuffixes` delivered by a signature-verified cloud `traffic-policy` without waiting for a client rebuild.
- **Expanded China direct routing** (#1850): Added domestic direct coverage including `.cn`, ToDesk, `assetcloud.zj.gov.cn`, Gitee, Jimeng (`jimeng.jianying.com`), and Aliyun Wanwang (`wanwang.aliyun.com`), and moved mainland `dashscope.aliyuncs.com` back to direct.
- **Zero-downtime policy key rotation** (#1851): Rotated the production `traffic-policy` Ed25519 key with legacy read fallback.
- **Per-site bandwidth & stall telemetry** (#1851): Tracks active flows and emits closed TCP/UDP byte totals, duration, and zero-download TCP stall diagnostics on close and disconnect.
