# Tono 0.0.45

这版全面加固了 Claude 及 AI 助手的住宅家宽分流边界，并修复了连接切换与断网恢复的稳定性问题。

- **Claude / AI 助手家宽分流全链路闭环**：
  - 将 Cloudflare Turnstile 人机验证（`challenges.cloudflare.com`、`cf-assets.www.cloudflare.com`）纳入家宽分流，避免主站走家宽但验证码走机房的指纹断层。
  - 将 Claude 前端遥测打点（`browser-intake-datadoghq.com`）、Statsig 特性配置与实验（`statsigapi.net`、`featuregates.org`）以及 Stripe Radar 支付防欺诈（`stripe.network`）全部接入家宽，彻底杜绝机房 IP 出现在 Claude 业务与风控日志中，降低封号风险。
- **连接与节点切换加固**：
  - 同一时间只允许一次节点切换修改选择器和 Windows 筛选平台（WFP），彻底消除连续切换时的并发竞争。
  - 网络原地恢复后，连接监控和控制面地址刷新保持运行，杜绝节点失效后界面假在线显示「已连接」。
  - 自动重连设置明确预算，确定性故障不再每 30 秒无休止重试，不再反复弹出管理员提权窗口。
  - 切换节点或点击「立即重试」即刻恢复重连预算，底层错误转换成用户友好的诊断提示。

安装包带有 Tono 自动更新签名，但没有 Authenticode 发布者证书，全新安装时 Windows SmartScreen 仍可能告警。
