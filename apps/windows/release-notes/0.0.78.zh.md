# Tono 0.0.78 — 客户手动测试 RC

这是手动安装测试候选，不是 Windows 稳定验收或自动更新推广。旧 0.0.77 RC 保留不变。支持 x64 Windows 10 22H2 / Windows 11。

- 修复绑了家宽的账号国内直连永远装不上：微信和国内网站一直走隧道，主界面显示「国内直连未开，微信也走隧道」。直连层现在按内核输出的完整规则核对（#1684）。预期：在稳定模式下用绑了家宽的账号连接后，这句提示消失，微信走直连。
- 内置 sing-box 内核从 v1.15.0-alpha.9 升到 v1.15.0-alpha.12（sing-tun 0.9.7 的 Windows TUN；hysteria2 不再强制 UDP 分片；FakeIP 存储与 DNS 重置修复）。路由规则行为不变。
- 精确 DNS 恢复失败后，仍指向 Tono 解析器的网卡由重启后的 Service 重置为 DHCP（#1605）。
- 系统代理指向没有监听的本机端口（如 `127.0.0.1:10090`）时，不再挡住线路页；界面说明原因并提供「清理失效代理」（#1675）。
- 出口身份连续 5 分钟未确认时，显示明确提示和「重新准备出口身份」（#1674）。
- 依赖补丁升级（tokio、serde_json、sha2、interprocess、@tauri-apps/api、rollup）。
- 0.0.77 的内容全部保留：默认仍是稳定模式；可选三层分流须显式断开再连接才生效；普通 DIRECT 仍仅支持公网 IPv4 TCP80/443。

## 安装与必须测试的项目

核验发布的 SHA-256。旧版先“恢复正常网络”，确认普通上网，再退出含托盘进程；正常以管理员运行安装器，保留固定 Program Files 路径，不使用受保护的应用内更新。**0.0.32–0.0.34 不可直接覆盖：**确认网络恢复后正常卸载、重启再装，可选时保留应用数据。恢复/卸载或旧安装校验失败就停止联系支持，不绕过门禁、不手删受保护资源。

先测稳定模式，再显式开启三层：连接/Activity、真实 DNS 及云/Home/直连出口、换云保持 Home 身份、保护路径失败、Core/Service 死亡、重启、显式恢复、两个方向保存模式后自动恢复、睡眠/唤醒和换 Wi-Fi。记录系统、旧版本、候选摘要；其它旧版覆盖及受保护自动升级仍需实测。

## 已知限制

- 现有流程提供 Tauri updater 签名，不是 Authenticode 发布者证书；可能显示 SmartScreen/未知发布者。不能关闭系统安全策略来测试；实际验签结果以交付回执为准。
- #1071/#1504 独立保留，HOLD #1643 多用户接管未包含。#1605 DHCP 兜底已包含但未经实机验证；DNS 恢复失败仍可能需要支持协助。
- G1–G3、真实 WFP/DNS 故障、升级回退和固定候选试用未验收；不要覆盖安装旧版回退，请联系支持。
- 保留已有日志偏好；新安装默认上传网络日志，可在设置修改。
