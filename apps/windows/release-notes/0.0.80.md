# Tono 0.0.80 — customer-test RC

Manual-install test candidate, not stable Windows qualification or automatic-update promotion. The 0.0.79 RC is retained unchanged. Requires x64 Windows 10 22H2 or Windows 11.

- **Fixed: Connect kept bouncing back after an unfinished Restore internet** (#1705). After a restart every Connect was refused with "the last restore did not finish", and the app asked for Restore internet again. Connect now runs Restore internet once by itself and connects, at most once per click. When Windows itself needs a restart, the app says so instead of retrying.
- **More AI services go through Home** (#1706). The AI list grows to 194 entries: Amp, Cursor, GitHub Copilot, Kiro and Amazon Q, Windsurf/Codeium, JetBrains AI, Hark, Mistral, ElevenLabs, Midjourney, Suno, Google Labs/Flow/Opal/Stitch, Llama, and the Poe, Perplexity and OpenAI pieces that were missing. With a Home line they follow it, as the rest of the AI list does.
- **Fixed: the sea animation kept the GPU busy in the background** (#1707). Behind another app, minimised or in the tray, the scene now holds its frame and resumes when you come back; sign-in and the intro no longer render a hidden second scene. Motion in the foreground is unchanged.
- Everything in 0.0.79 is retained: Stable remains the default; opt-in Three-tier is applied only after an explicit disconnect/reconnect; ordinary DIRECT stays public IPv4 TCP80/443 only; China Mobile Cloud and the MIIT filing site go DIRECT.

## Installation and required tests

Verify the published SHA-256. Restore Normal Internet in the old Tono, confirm ordinary internet, then quit including the tray. Run the installer normally as administrator at the fixed Program Files location; do not use protected in-app update for this test. **0.0.32–0.0.34 must not be directly overwritten:** after verified restoration, normally uninstall, restart and install this candidate, retaining application data where offered. Stop and contact support if restore/uninstall or existing-installation validation fails; never bypass the gate or delete protected resources manually.

Test Stable first, then explicitly enable Three-tier: connection/Activity, actual DNS and cloud/Home/DIRECT egress, Home identity while changing cloud, protected-path failure, Core/Service death, restart, explicit restore, save-mode-then-auto-recovery in both directions, sleep/wake and Wi-Fi changes. Also: after a restart that left Restore unfinished, one Connect restores and connects; with Tono behind another app, Task Manager shows the GPU near idle. Record OS, old version and candidate hash. Other-version manual overwrite and protected automatic upgrades remain unqualified.

## Known limits

- The pipeline uses the Tauri updater signature, not an Authenticode publisher certificate. SmartScreen/unknown-publisher warnings may appear; do not disable security policies to run the candidate. Check the delivery receipt for actual package signing results.
- #1071/#1504 remain independent; HOLD #1643 multi-user takeover is not included. The #1605 DHCP fallback is included but unverified on hardware; DNS restoration failure may still require support-assisted recovery.
- G1–G3, real WFP/DNS fault behavior, upgrade/rollback and a fixed-candidate trial remain unverified. Do not install an older version over this candidate for rollback; contact support.
- Existing logging preferences remain; fresh installs upload network logs by default, configurable in Settings.
