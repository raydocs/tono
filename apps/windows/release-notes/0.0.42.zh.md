# Tono 0.0.42

这版修的是界面在撒谎：显示的数字、国旗、计数和实际情况对不上。连接和路由的行为没有改动。

- 延迟以前只在连上的那一刻测一次，测到的是冷启动握手的值（常见八九百毫秒），然后整个会话都不再更新。现在会持续重测，显示的是线路真正的水平；切换节点后也会立刻重测，不再拿上一个节点的数字充数。
- 切换节点失败时，界面会退回原来的节点并说明原因。以前失败只回滚了路由，卡片、托盘和首页仍显示新节点，流量其实还走着旧的，而且不会自己纠正。
- 连接进行中切换节点，界面不再显示一个这次连接并没有在用的节点。
- 「已拦住直连」状态下点连接胶囊会先确认。以前同一屏两个入口，只有进度卡那个会确认，误点一下就把保护解除了。
- 「重试」和「恢复正常网络」失败时会把原因显示出来，以前只写进控制台，按钮看起来像坏的。
- 未测速的节点显示「未测速」，不再是一个破折号。
- 托盘里的延迟和首页统一成同一种说法和同一套颜色。
- 应用列表里，回落到云端出口的连接不再标成「家宽」——那些流量并没有走你家里的宽带。
- 断开时筛选栏不再消失，你选的标签和搜索词会保留。
- 节点地区显示「美国」「日本」，不再是 US、JP。
- 两处服务问题（基础筛选引擎未运行、防火墙引擎无响应）以前会连着内部前缀一起原样弹出来，现在是正常的中文说明。
- 离开活动页会释放连接快照；读不到流量时的重试改为逐步退避，不再每 4 秒重连一次。

安装包未附 Authenticode 证书，全新安装时 SmartScreen 会告警。
