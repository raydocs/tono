# Tono 0.0.76 — customer-test candidate

This is a new manual-install test candidate, not a stable release or completed Windows-device qualification. Production automatic-update feeds are unchanged.

- Includes the merged independent Restore Normal Internet worker, Wi-Fi release retries, Service/update fixes, signed DIRECT-policy admission and current main's pinned Core/toolchain updates. Held or design-blocked branches are not included.
- Requires Windows x64, Windows 10 22H2 or Windows 11. No phone or Linux package is included.
- Download and verify the published SHA-256 first. In the old Tono, choose **Restore Normal Internet**, confirm ordinary internet works, then quit including the tray. Run this installer normally as administrator and keep the fixed Program Files location. Do not request a protected in-app update for this test.
- **Windows 0.0.32–0.0.34 are excluded from direct overwrite:** their legacy runtime filename is incompatible with the current replacement preflight. After verified network restoration, uninstall normally, restart, confirm internet works, then install this candidate. Preserve application data if the uninstaller offers that choice. If uninstall fails or the new installer reports an invalid existing installation, stop and contact support; do not remove protected resources or bypass the gate.
- Other previous versions may be manually overwritten for testing, but each customer's version/state still needs qualification. Record the old version and installer result; an unconfigured hosted install/repair test is not a connected customer upgrade.
- Please test connection/Activity, DNS and NRPT restoration, hotspot-to-Wi-Fi changes, Restore followed by two minutes without relocking, immediate Connect, restart and sleep/wake.

## Known limits

- The updater payload uses the existing Tauri signature. There is no Authenticode publisher certificate in the current release pipeline; Windows may show an unknown-publisher/SmartScreen warning. Do not disable system security policies to run the test.
- The DHCP fallback in Draft [#1605](https://github.com/raydocs/tono/pull/1605) and multi-user takeover in HOLD [#1643](https://github.com/raydocs/tono/pull/1643) are not included. DNS restore failure can still require support-assisted recovery.
- Hardware fail-closed, old-client upgrade and sleep/wake acceptance are pending. Existing logging preferences are retained; new installations upload traffic logs by default, configurable in Settings.
- Do not install an older version over this candidate for rollback; contact support for a compatible recovery path.
