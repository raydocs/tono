# Tono 0.0.43

这版针对一次真实故障：Tono 服务没在运行时，界面只说「保护中，未连上」，诊断信息里全是「未知」，看不出到底哪里坏了。连接和路由的行为没有改动。

- Tono 启动时会自检服务有没有在运行。没运行的话顶部会出现提示，说明原因，并提供一个「修复」按钮——点一次授权管理员，Tono 会把需要的服务都启动起来，不用你手动敲命令。
- 安装和修复时会确保 Windows 的基础筛选引擎（BFE）处于可用状态。Tono 服务依赖它才能启动，而这个引擎会被一些「网络加速」类软件关掉。
- 网络频繁变化时不再反复自检。以前 Windows 每报告一次网络变化，就会立刻做一次完整的穿隧道连通性检查；在网卡状态不稳的电脑上（多见于装了网络加速类软件），这些检查会互相重叠堆积，把客户端拖慢。现在一次成功的检查在短时间内可复用。
- 仪表盘读不到数据时，原因会记进诊断日志。以前这类失败只写在本地文件里，技术支持看不到，只能反复问你要日志。

如果遇到「能上国内网站、外网打不开」，先看顶部有没有服务提示；有的话点「修复」。想手动处理，就用管理员身份的 PowerShell 依次运行 `sc.exe config BFE start= auto`、`sc.exe start BFE`、`sc.exe start TonoService`，然后重新连接。

安装包未附 Authenticode 证书，全新安装时 SmartScreen 会告警。
