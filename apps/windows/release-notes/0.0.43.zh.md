# Tono 0.0.43

这版针对一次真实故障：Tono 服务没在运行时，界面只说「保护中，未连上」，诊断信息里全是「未知」，看不出到底哪里坏了。连接和路由的行为没有改动。

- 服务没起来时，现在会直接说明原因和怎么修。TonoService 依赖 Windows 的基础筛选引擎（BFE），BFE 被关掉时 Windows 会拒绝启动它，而且重启也不会重试——这种情况以前只显示「未连上」，现在会告诉你运行 `sc.exe start BFE` 再启动 TonoService。
- 网络频繁变化时不再反复自检。以前 Windows 每报告一次网络变化，就会立刻做一次完整的穿隧道连通性检查；在网卡状态不稳的电脑上（多见于装了网络加速类软件），这些检查会互相重叠堆积，把客户端拖慢。现在一次成功的检查在短时间内可复用。
- 仪表盘读不到数据时，原因会记进诊断日志。以前这类失败只写在本地文件里，技术支持看不到，只能反复问你要日志。

如果你遇到「能上国内网站、外网打不开」，多半就是上面第一条：用管理员身份的 PowerShell 依次运行 `sc.exe config BFE start= auto`、`sc.exe start BFE`、`sc.exe start TonoService`，然后重新连接。

安装包未附 Authenticode 证书，全新安装时 SmartScreen 会告警。
