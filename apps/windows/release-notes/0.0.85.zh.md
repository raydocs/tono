# Tono 0.0.85

支持 x64 Windows 10 22H2 / Windows 11。

## 相比 0.0.84 的更新

- **支持签名策略直连后缀云端热更新**（#1851）：Windows `sing-box` 内核现可直接放行经 Ed25519 签名校验的 `directSuffixes`，后续新增国内直连站点无需重新发版安装。
- **扩展国内直连范围**（#1850）：新增 `.cn`、ToDesk、政采云（`assetcloud.zj.gov.cn`）、Gitee、即梦（`jimeng.jianying.com`）、万网（`wanwang.aliyun.com`）直连，并将国内阿里云百炼（`dashscope.aliyuncs.com`）切回直连。
- **策略签名密钥平滑轮换**（#1851）：更新主签名公钥并保留旧密钥只读兼容。
- **网站流量与卡顿统计**（#1851）：在连接关闭与断开时采集各站点真实上下行字节、耗时与零下行卡顿标记，用于后台全局监控面板。
