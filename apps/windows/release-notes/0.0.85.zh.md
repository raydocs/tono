# 0.0.85
> 支持 x64 Windows 10 22H2 / Windows 11。本版新增签名策略直连后缀云端热更新、扩展国内直连范围、平滑轮换策略签名密钥并补齐站点卡顿统计。

- 支持签名策略直连后缀云端热更新（#1851）：Windows `sing-box` 内核可直接放行经 Ed25519 签名校验的 `directSuffixes`，后续新增国内直连站点无需重新发版安装
- 扩展国内直连范围（#1850）：新增 `.cn`、ToDesk、政采云（`assetcloud.zj.gov.cn`）、Gitee、即梦（`jimeng.jianying.com`）、万网（`wanwang.aliyun.com`）直连，并将国内阿里云百炼（`dashscope.aliyuncs.com`）切回直连
- 策略签名密钥平滑轮换（#1851）：更新主签名公钥并保留旧密钥只读兼容
- 网站流量与卡顿统计（#1851）：在连接关闭与断开时采集各站点真实上下行字节、耗时与零下行卡顿标记，用于后台全局监控面板

## 时间线
Windows 端正式支持经签名的云端策略 `directSuffixes` 热更新并内置 `.cn` 及高频远程/办公国内站点直连，完成策略签名密钥平滑轮换与每站点上下行及卡顿统计闭环。服务协议版本不变，可通过原生 v1 或 Tauri 更新器升级。

## 限制
- 安装包未附 Authenticode 证书，全新安装时 Windows SmartScreen 会告警
- 0.0.32–0.0.34 旧版不可直接覆盖升级：需先在网络恢复后正常卸载旧版并重启确认网络正常，再安装本版
