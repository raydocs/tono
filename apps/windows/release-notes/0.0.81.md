# Tono 0.0.81 — customer-test RC

Manual-install test candidate that replaces the 0.0.80 RC, not stable Windows qualification or automatic-update promotion. Requires x64 Windows 10 22H2 or Windows 11.

- **Fixed: a failed connection no longer leaves you guessing** (#1759). "The connection didn't complete" now says what to do next. When the chosen server itself did not answer, the message says so and offers another server; a plain network failure says to retry and then pick another server; a tunnel check or another VPN holding the network is named as such. A failure Tono could not classify shows its support code on the sentence.
- **Fixed: a flapping Wi-Fi or adapter kept rebuilding the tunnel** (#1759). Every two failed network-change checks used to tear the tunnel down and reconnect, without limit. Tono now rebuilds at most three times an hour, then keeps the tunnel up and shows the "this route dropped several times" hint with a Switch-server action.
- **Fixed: one slow Google check counted as a broken tunnel** (#1759). The protected-tunnel health check now asks two independent sites and only reports a failure when both fail.
- **Fixed: "The connection didn't complete" after an update or Restore internet took over** (#1759). When a newer action superseded a Connect, Tono now says the attempt was cancelled and to connect again, instead of reporting a network failure.
- **Fixed: Chrome or Edge being slow to answer blocked connecting** (#1759). The Secure DNS check in the browsers used to give up after five seconds and refuse to connect. It now retries once, and if it still cannot finish it asks you to close Chrome and Edge, then connect again.
- Everything in 0.0.80 is retained: Connect runs Restore internet once by itself after an unfinished restore; the AI list has 194 entries; the sea animation idles in the background; Stable remains the default and ordinary DIRECT stays public IPv4 TCP80/443 only.

## Installation and required tests

Verify the published SHA-256. Restore Normal Internet in the old Tono, confirm ordinary internet, then quit including the tray. Run the installer normally as administrator at the fixed Program Files location; do not use protected in-app update for this test. **0.0.32–0.0.34 must not be directly overwritten:** after verified restoration, normally uninstall, restart and install this candidate, retaining application data where offered. Stop and contact support if restore/uninstall or existing-installation validation fails; never bypass the gate or delete protected resources manually.

Test Stable first, then explicitly enable Three-tier: connection/Activity, actual DNS and cloud/Home/DIRECT egress, Home identity while changing cloud, protected-path failure, Core/Service death, restart, explicit restore, save-mode-then-auto-recovery in both directions, sleep/wake and Wi-Fi changes. Also for this candidate: pick a server that is down and confirm the message offers another server; toggle Wi-Fi off and on repeatedly for a few minutes and confirm the tunnel stays up after the third rebuild and the route hint appears; with Chrome open on a slow disk, Connect should still finish or name Chrome and Edge. Record OS, old version and candidate hash. Other-version manual overwrite and protected automatic upgrades remain unqualified.

## Known limits

- The pipeline uses the Tauri updater signature, not an Authenticode publisher certificate. SmartScreen/unknown-publisher warnings may appear; do not disable security policies to run the candidate. Check the delivery receipt for actual package signing results.
- When the controller, tunnel and proxy checks all fail after the tunnel is locked, Tono still cannot tell a dead server from a broken local tunnel; that message keeps its generic code and the support code.
- #1071/#1504 remain independent; HOLD #1643 multi-user takeover and #1733 are not included unless merged before the build. The #1605 DHCP fallback is included but unverified on hardware; DNS restoration failure may still require support-assisted recovery.
- G1–G3, real WFP/DNS fault behavior, upgrade/rollback and a fixed-candidate trial remain unverified. Do not install an older version over this candidate for rollback; contact support.
- Existing logging preferences remain; fresh installs upload network logs by default, configurable in Settings.
