# 0.0.86
> 支持 x64 Windows 10 22H2 / Windows 11。本版新增签名策略 TCP 直连 IP 支持，之后新增或调整直连 IP 只需推送策略。

- 签名 TCP 直连 IP（#1856）：签名 `traffic-policy` 可携带 `tcpDirectAddresses`（无域名的 IPv4 TCP 目的地）与 v5 `tcpEndpoints`，Windows 服务放行并直连这些地址，无需重新发版

## 时间线
客户端开始识别云端签名策略中的 TCP 直连 IP；生产策略 rev 11 已带 18 个国金 QMT IPv4。

## 限制
- 安装包未附 Authenticode 证书，全新安装时 Windows SmartScreen 会告警
- 0.0.32–0.0.34 旧版不可直接覆盖升级：需先在网络恢复后正常卸载旧版并重启确认网络正常，再安装本版
