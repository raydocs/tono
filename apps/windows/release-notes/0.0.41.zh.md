# Tono 0.0.41

Windows 测试/对客候选。连接前备好「恢复正常网络」。

- 微信、飞书、QQ、会议走直连；Claude、ChatGPT、Cursor 走家里宽带，减少被当成机房 IP。
- 登录会显示验证码发到哪封完整邮箱，以及发件人 Tono &lt;login@lecvia.com&gt;。
- 第一次连接前会提示：允许管理员、关掉系统加密 DNS、关掉浏览器安全 DNS。加密 DNS 失败可直接打开 Windows 网络设置。
- 第一次连上后会打开开机自启，可在设置里关掉。
- 支持页可打开 WebRTC 泄漏检测，并可一键复制版本号给客服。
- 连接失败改用人话，包括加密 DNS。
- 关掉窗口不会断开，Tono 继续在托盘运行。
- 连上后才会慢慢上报访问过的网站，避免拖慢连接。

安装包未附 Authenticode 证书，全新安装时 SmartScreen 会告警。
