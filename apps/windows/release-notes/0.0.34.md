# Tono 0.0.34

This build updates automatically from 0.0.33. It focuses on polish and Chinese
language quality.

- Switching servers now confirms with a small toast naming the server you
  landed on, instead of changing silently.
- Chinese text across the app was reviewed and tightened: servers are
  consistently called 节点, punctuation is full-width in Chinese contexts, and
  a handful of awkward translations were rewritten.
- The server badge artwork was rebuilt as a shared brand mark, matching the
  macOS app pixel for pixel.
- Small consistency fixes to the selected-server highlight and card borders.
