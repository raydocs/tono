# Tono 0.0.77 — 客户手动测试 RC

这是手动安装测试候选，不是 Windows 稳定验收或自动更新推广。旧 0.0.76 RC 保留不变。支持 x64 Windows 10 22H2 / Windows 11。

- 设置新增可选“三层分流”，默认仍是稳定模式；保存后显式断开重连才生效，自动恢复沿用当前会话捕获的模式。
- 优先级：21 项视频云例外 → 原 166 项 AI/具名 Home 经云到原 assigned Home → 明确云名单 → 其余受支持普通流量 DIRECT（含未分类）。已识别 Home/云端解析或拨号失败不降级直连；固定 DoH、Core 死亡阻断保留。
- 普通 DIRECT 仅支持公网 IPv4 TCP80/443，业务 UDP/QUIC、IPv6、LAN 和其他普通端口未支持。ECH、缓存/裸 IP、自带 DoH 可能隐藏 AI 而默认直连，不能保证未知 AI 走 Home。Home 条目含具名非 AI 服务，不是全量 AI 分类。
- 修复晚解析 Home CIDR 被直连、自动恢复读取下次模式，补 marker 清除失败恢复回归；模拟/托管故障测试不是实际 WFP 或流量验收。冷启动仍需云证明，模式/规则/换云须显式断开重连。

## 安装与必须测试的项目

核验发布的 SHA-256。旧版先“恢复正常网络”，确认普通上网，再退出含托盘进程；正常以管理员运行安装器，保留固定 Program Files 路径，不使用受保护的应用内更新。**0.0.32–0.0.34 不可直接覆盖：**确认网络恢复后正常卸载、重启再装，可选时保留应用数据。恢复/卸载或旧安装校验失败就停止联系支持，不绕过门禁、不手删受保护资源。

先测稳定模式，再显式开启三层：连接/Activity、真实 DNS 及云/Home/直连出口、换云保持 Home 身份、保护路径失败、Core/Service 死亡、重启、显式恢复、两个方向保存模式后自动恢复、睡眠/唤醒和换 Wi-Fi。记录系统、旧版本、候选摘要；其它旧版覆盖及受保护自动升级仍需实测。

## 已知限制

- 现有流程提供 Tauri updater 签名，不是 Authenticode 发布者证书；可能显示 SmartScreen/未知发布者。不能关闭系统安全策略来测试；实际验签结果以交付回执为准。
- #1071/#1504 独立保留，Draft #1605 DHCP/DNS fallback、HOLD #1643 多用户接管未包含；DNS 恢复失败可能仍需支持协助。
- G1–G3、真实 WFP/DNS 故障、升级回退和固定候选试用未验收；不要覆盖安装旧版回退，请联系支持。
- 保留已有日志偏好；新安装默认上传网络日志，可在设置修改。
