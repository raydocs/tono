# Tono Windows 0.0.72

- 改善连接恢复、服务诊断与配置校验；不可用的必需家宽出口会明确拒绝连接，不再悄悄退回云出口。
- 补齐 Claude 相关支付、验证与统计依赖的家宽链式分流，包括 Stripe、Link、hCaptcha 和 Statsig。规则按目标域名匹配，不要求逐个适配浏览器。
- 改善活动页的进程识别与路由展示。
- Windows 和 macOS 源码版本统一为 0.0.72；两平台安装包独立签名、验收和发布。

## 验证范围与已知限制

本轮 Windows 候选包已在 Windows 11 实机验证安装、正常连接、保护机制、受保护 DNS，以及无需登录的支付依赖 TLS 和公开出口探测；对应源码的 Windows、macOS、Services CI 已通过。这不等于已验证所有网站、银行 3DS、浏览器 Secure DNS 设置或异常断电恢复。

- [#26](https://github.com/raydocs/tono/issues/26)：完整的受保护自动更新生命周期尚未完成端到端证明。手动升级请先在 Tono 中正常断开连接，再退出应用并安装；不要将本次发布视为连接中升级或崩溃恢复认证。
- [#4](https://github.com/raydocs/tono/issues/4)、[#5](https://github.com/raydocs/tono/issues/5)：计量切换与计数器代际限制仍单独跟踪，本次桌面发布不执行计量迁移。
- 安装包使用 Tauri 更新签名，不含 Windows Authenticode 发布者签名，SmartScreen 仍可能提示。

发布安装包与推进自动更新频道是独立操作；未完成升级链路验收前，不推进自动更新频道。
