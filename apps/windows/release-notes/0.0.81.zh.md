# Tono 0.0.81 — 客户手动测试 RC

这是替代 0.0.80 RC 的手动安装测试候选，不是 Windows 稳定验收或自动更新推广。支持 x64 Windows 10 22H2 / Windows 11。

- **修复：连接失败后只看到「连接没有完成」，不知道该做什么**（#1759）。现在每条失败提示都写明下一步：所选节点本身没应答时会直说，并提供换节点；普通网络失败提示先重试、仍失败再换节点；隧道检查没过或别的 VPN 占住网络时会点名。Tono 无法归类的失败会把支持码写在提示里。
- **修复：Wi-Fi 或网卡反复抖动时，隧道被一遍遍重建**（#1759）。以前网络变化检查连续两次失败就整个拆掉重连，没有上限。现在一小时最多重建三次，之后保持隧道不动，并显示「这条线路最近多次中断」的提示和换节点按钮。
- **修复：Google 一次检查慢就被当成隧道坏了**（#1759）。受保护隧道的健康检查改为问两个互不相关的站点，两个都失败才算失败。
- **修复：更新或「恢复正常网络」接管后，连接显示「连接没有完成」**（#1759）。更新的操作取代了这次连接时，现在会说明这次尝试已作废、请重新连接，而不是报网络错误。
- **修复：Chrome 或 Edge 响应慢会挡住连接**（#1759）。浏览器安全 DNS 检查以前五秒没结果就拒绝连接。现在会再试一次；仍没完成时提示先关闭 Chrome 和 Edge，再重新连接。
- 0.0.80 的内容全部保留：恢复没做完时连接会自己先恢复一次；AI 名单 194 条；海景动画后台停帧；默认仍是稳定模式，普通 DIRECT 仍仅支持公网 IPv4 TCP80/443。

## 安装与必须测试的项目

先核验发布的 SHA-256。旧 Tono 选择「恢复正常网络」，确认普通上网正常，再连托盘一起退出。以管理员身份在固定的 Program Files 位置正常运行安装程序；本次测试不要用受保护的应用内更新。**0.0.32–0.0.34 不能直接覆盖：**确认恢复后，正常卸载、重启再安装本候选，有保留应用数据选项时保留。恢复/卸载或已装校验失败就停止并联系支持，不要绕过门槛或手删受保护资源。

先测稳定模式，再显式打开三层分流：连接/活动、实际 DNS 与云端/家宽/直连出口、换云端时家宽身份、受保护路径故障、Core/Service 死亡、重启、显式恢复、双向省流自动恢复、睡眠/唤醒与 Wi-Fi 切换。本候选另加：选一台挂掉的节点，确认提示里有换节点；反复开关 Wi-Fi 几分钟，确认第三次重建后隧道保持、出现线路提示；慢盘上开着 Chrome 连接，应能完成或点名 Chrome 和 Edge。记录系统、旧版本与候选哈希。跨版本手动覆盖和受保护自动升级仍未验收。

## 已知限制

- 流水线用的是 Tauri 更新签名，不是 Authenticode 发布者证书，可能出现 SmartScreen/未知发布者提示；不要为运行候选关闭安全策略。实际包签名结果以交付回执为准。
- 隧道锁定后控制器、隧道、代理三项检查全失败时，Tono 仍分不清是节点死了还是本机隧道坏了，这条提示保留通用说法和支持码。
- #1071/#1504 仍独立；HOLD #1643 多用户接管与 #1733 除非在构建前合入，否则不包含。#1605 DHCP 回退已包含但未在真机验证；DNS 恢复失败仍可能需要支持协助。
- G1–G3、真实 WFP/DNS 故障行为、升级/回退与固定候选试用尚未验收。不要为回退在本候选上覆盖安装旧版本，请联系支持。
- 保留已有日志偏好；新安装默认上传网络日志，可在设置调整。
