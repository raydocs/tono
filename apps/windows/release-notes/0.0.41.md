# Tono 0.0.41

Windows test and customer-candidate build. Keep Restore Network ready.

- WeChat, Feishu, QQ, and Meeting go direct. Claude, ChatGPT, and Cursor use home broadband so those accounts do not look like a datacenter.
- Sign-in shows the exact mailbox the code was sent to, and the sender Tono &lt;login@lecvia.com&gt;.
- First-connect checklist: allow the admin prompt, turn off Windows Encrypted DNS, turn off browser Secure DNS. Encrypted DNS failures open Windows Network settings.
- Launch at startup turns on after the first successful connect. You can turn it off in Settings.
- Support includes a WebRTC leak check and a one-click version copy.
- Connect failures are shown in plain language, including Encrypted DNS.
- Closing the window does not disconnect; Tono stays in the tray.
- Destination samples upload slowly after connect so the tunnel is not busy.

The installer is unsigned. Windows SmartScreen will warn on a first install.
