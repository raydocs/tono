# Tono 0.0.42

This build fixes the interface making claims the data did not support: numbers, flags, and counts that disagreed with what was actually happening. Connection and routing behaviour is unchanged.

- Latency was measured once at connect — a cold handshake, commonly 700–900ms — and then frozen for the rest of the session. It is re-measured continuously now, so the number reflects the line you actually have, and a node switch re-measures immediately instead of showing the previous node's reading.
- A failed node switch now falls back to the previous node and says why. Before, the routing rolled back but the card, the tray, and the dashboard all kept showing the node that was never adopted, while traffic still left through the old one — and nothing corrected it.
- Switching nodes mid-connect no longer shows a node the attempt is not using.
- The connect pill asks for confirmation before releasing protection while direct traffic is blocked. One screen offered two ways to do it and only the progress card confirmed.
- Retry and Restore Normal Internet now show the reason when they fail, instead of writing it to the console and looking like dead buttons.
- Untested nodes say so, instead of showing a bare dash.
- The tray and the dashboard now speak about latency in the same units, with the same colour bands.
- In the app list, a connection that fell back to the cloud exit is no longer badged as home broadband — those bytes did not use your home connection.
- Disconnecting no longer unmounts the filter bar, so your tab and search text survive.
- Node regions read as country names rather than US and JP.
- Two Service failures (Base Filtering Engine not running, firewall engine wedged) used to surface with their internal prefix attached; both are proper messages now.
- Leaving Activity releases the connection snapshot, and the traffic retry backs off instead of reconnecting every four seconds.

The installer is unsigned. Windows SmartScreen will warn on a first install.
