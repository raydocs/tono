STATUS

现在对外提供的版本

「已发布」只表示代码打过包。「用户拿得到」要看本站的 Manifest、macOS 更新源和 Windows 更新通道是否指向同一版。

HOW TO READ

以哪里为准

看首页两张卡片，或直接打开机器可读的 Manifest。Mac 更新看 Appcast，Windows 更新看 latest.json。

GitHub 的 Releases 列表不是判断依据。曾经有过「仓库里有新包，更新通道还停在旧版」的情况，结果已安装的用户根本收不到。

本页不实时探测每台服务器是否在线。节点健康在客户端连接时核对，不在下载站上承诺。

版本数字以 Manifest 为准。本页只解释怎么读，不另记一套数字。
