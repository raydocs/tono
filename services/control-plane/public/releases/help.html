HELP

安装与更新

安装包只从本站下载。GitHub 上的发布记录是存档，不作为日常下载入口。

MAC

在 Mac 上安装

下载当前 ZIP，解压后把 Tono 拖进「应用程序」。首次连接时，系统会请你批准网络组件和管理员权限，用来开启断网保护。

已经装过 Tono 的电脑一般会自己检查更新。不想等的话，打开应用里的检查更新即可。

WINDOWS

在 Windows 上安装

下载安装包后按提示完成安装。首次连接同样需要批准系统服务，用来在断线时拦住直连流量。

已安装的版本会从本站读取更新信息。不要改成从 GitHub 或其他地址拉安装包。

VERIFY

下载后怎么核对

首页卡片上的文件名，应和 manifest.json 里当前版本的文件名、大小、SHA-256 一致。对不上就不要安装。

macOS 可用 shasum -a 256 文件名.zip；Windows 可用 PowerShell 的 Get-FileHash。

安全问题请通过 GitHub Security Advisory 私下报告，不要发到公开 issue。
